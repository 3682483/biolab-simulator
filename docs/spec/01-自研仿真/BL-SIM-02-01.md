## 2. 学科定位

人教版必修一第 4 章第 1 节。课标要求：说明渗透作用的条件与原理，观察并解释植物细胞的质壁分离与复原。前置：水与无机盐；后续：物质跨膜运输、水分代谢与农业生产。

## 3. 教学目标

1. 能说出渗透作用发生的两个条件（半透膜、膜两侧溶液浓度差）。
2. 能用"单位体积内水分子数"解释净水流的**方向**，并说明水分子是双向运动的。
3. 能解释质壁分离的成因（原生质层伸缩性大于细胞壁）与复原条件。
4. 能判断哪些溶液可导致质壁分离后自动复原（溶质可透过膜）。

## 4. 知识点解析

必须准确表述：

- 渗透作用：水分子（或其他溶剂分子）通过半透膜，从**低浓度溶液**向**高浓度溶液**扩散；实质是单位体积内水分子数的差异。
- 质壁分离：外界溶液浓度 > 细胞液浓度 → 细胞失水 → **原生质层**收缩、与细胞壁分离；细胞壁伸缩性小是外因，原生质层伸缩性大是内因。
- 复原条件：外界溶液浓度 < 细胞液浓度（如换清水），或使用可透过膜的溶质（尿素、硝酸钾、乙二醇）使细胞液浓度反超。
- 死细胞不能发生质壁分离（原生质层失去选择透过性）。

常见错误概念：

1. 认为"细胞壁收缩了"——错，细胞壁几乎不收缩，是原生质层收缩。
2. 认为 0.3 g/mL 蔗糖溶液处理后会**自动**复原——错，蔗糖不能透过膜，必须换清水。
3. 认为水分子只向高浓度一侧移动——错，双向运动，净流量朝向高浓度侧。
4. 认为任何细胞都能发生质壁分离——需具**大液泡**的成熟植物活细胞。

## 5. 界面设计

主画布：U 形管/漏斗装置 + 显微视野双视图（左装置液面、右细胞状态）。控制区：漏斗内与烧杯溶液浓度、溶质类型（蔗糖/尿素/KNO₃）、观察模式（装置/细胞）。数据区：液面高度 Δh、细胞体积变化率、水分子进出通量。讲解区：条件判定与易错提示。

## 6. 互动素材

漏斗与半透膜装置、液面刻度、水分粒子流（左右双向，数量差体现净流）、植物细胞剖面（细胞壁、原生质层、液泡）、质壁分离程度可视化。

## 7. 标注要求

等级 **A2**。标注项：半透膜、漏斗内溶液、烧杯溶液、液面高度差 Δh、细胞壁、原生质层、液泡、细胞液。原生质层必须与细胞壁分别标注，避免"整层收缩"的误读。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 设定两侧浓度 | 显示浓度差→预期的净水流方向箭头 | 先预测后验证 |
| 开始实验 | 液面 Δh 随时间变化并与浓度差成正比 | 建立定量关系 |
| 切换到细胞视图 | 原生质层收缩、液泡变小、质壁分离程度可视 | 对应到细胞层面 |
| 更换为尿素溶液 | 先分离后自动复原，曲线呈先升后降 | 理解溶质可透过 |
| 换回清水 | 细胞吸水复原 | 掌握复原条件 |
| 尝试死细胞 | 无变化并提示"原生质层失去选择透过性" | 修正"任何细胞都能发生" |

## 9. 参数与模型

- Δh ∝ 浓度差（简化线性，标注"定性示意"）；渗透平衡时两侧浓度趋于相等（考虑液柱静压时给出定性说明）
- 细胞体积变化：可用相对体积 V/V₀ 在 0.6–1.15 之间变化
- 自动复原曲线：尿素进入细胞的时间常数可调（3–10 s）

## 10. 三维与可视化规范

等级 **L2**：装置用 2.5D 轴测呈现，细胞可用简化三维剖面（可 ±20° 转动以看清原生质层与细胞壁的分离间隙）。不做全三维分子级模拟。

## 11. 验收标准

- [ ] 浓度差为零时净水流为零，水分子仍双向运动
- [ ] 蔗糖溶液处理后换清水才复原，不出现自动复原
- [ ] 尿素/KNO₃ 处理后可自动复原且曲线先降后升
- [ ] 细胞壁与原生质层分别标注，收缩者明确为原生质层
- [ ] 死细胞对照组无变化并给出原因

## 12. 现有实现问题

> 待与源码逐条核对。

- 注册步骤仅"比较浓度差与 Δh"，未覆盖质壁分离复原与溶质可透过情形

- 缺少死细胞对照，易残留"任何细胞都能质壁分离"的错误概念
