## 2. 学科定位

人教版必修一第 2 章第 4 节。课标要求：说明氨基酸的结构特点及蛋白质的功能，能计算肽键数与脱水数。前置：氨基、羧基、R 基；后续：蛋白质的结构层次、分泌蛋白、酶与抗体。

## 3. 教学目标

1. 能写出氨基酸的通用结构式，指出氨基、羧基与 R 基的位置。
2. 能说明脱水缩合的化学本质：一个氨基酸的羧基与另一个氨基酸的氨基脱去一分子水形成肽键。
3. 能计算：n 个氨基酸形成 m 条肽链时的肽键数 = 脱水数 = n − m；环肽为 n。
4. 能定性说明 R 基种类决定蛋白质结构与功能的多样性。

## 4. 知识点解析

必须准确表述：

- 氨基酸结构通式：中心碳原子连接氨基（—NH₂）、羧基（—COOH）、氢原子（—H）与 R 基。
- 脱水缩合：—COOH 与 —NH₂ 脱去 H₂O 形成 —CO—NH—（肽键）。
- n 个氨基酸形成 m 条**链状**肽：肽键数 = 脱水数 = n − m；相对分子质量减少 18(n − m)。
- n 个氨基酸形成**环状**肽：肽键数 = 脱水数 = n。
- 若含二硫键（—S—S—），每形成一个二硫键再脱去 2 个 H。

常见错误概念：

1. 把"肽键数 = n − 1"无条件套用到多肽链或环肽。
2. 计算相对分子质量时漏掉二硫键脱氢。
3. 认为氨基酸种类由肽键数量决定（实由 R 基种类决定）。

## 6. 互动素材

- 氨基酸球棍模型（20 种 R 基的简化表示，至少含甘氨酸、丙氨酸、半胱氨酸）
- 肽键形成动画（化合键断裂—脱 H₂O—成键三阶段）
- 肽链盘曲折叠示意（体现 R 基相互作用与二硫键锁定）

## 7. 标注要求

等级 **A3**（空间锚点）。标注项：氨基（amino group）、羧基（carboxyl group）、R 基（side chain）、肽键（peptide bond）、肽链（polypeptide chain）、二硫键（disulfide bond）。每条标注须绑定模型节点，模型旋转时引线随动；肽键标注需同时显示"—CO—NH—"结构简式。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 设定 n 与 m | 画布显示 m 条待生长肽链，数据区清零 | 建立初始条件 |
| 点击"缩合" | 两个氨基酸靠近、羧基与氨基对位、脱出 H₂O 小球、生成肽键 | 看清反应部位与产物 |
| 累加至结束 | 统计面板显示 n−m 与 18(n−m) | 公式不是在文字里给，而是由操作推出 |
| 切换环状 | 首尾缩合，肽键数变为 n | 打破"n−1"的机械记忆 |
| 选择含半胱氨酸的 R 基 | 出现二硫键，统计再减 2H | 认识共价交联 |
| 改变 R 基组合 | 肽链折叠形态变化 | 关联结构多样性 |

## 9. 参数与模型

- 脱水相对分子质量：18；平均氨基酸残基相对分子质量取 110（用于估算，需标注"平均"）
- 计算式：链状 M = 110n − 18(n − m) − 2k（k 为二硫键数）；环状 M = 110n − 18n − 2k
- 边界：n ≥ 2；m ≤ n；环状时 m 恒为 1

## 10. 三维与可视化规范

等级 **L2**（2.5D）：肽链以轴测视角呈现，支持 ±25° 伪旋转与缩放；肽键局部可放大至键角可见。不使用全三维原子模型（认知负担过大且与教学目标无关）。配色：氨基蓝、羧基红、R 基灰、肽键高亮金。

## 12. 现有实现问题

> 待与源码逐条核对；以下为基于注册信息的结构性问题。

- 注册步骤强调"推算肽键数 = n − 1"，未覆盖多链与环肽，直接强化了错误概念
- 未涉及二硫键对相对分子质量的影响
- R 基仅作"侧链互补"演示，未与氨基酸种类/蛋白质多样性建立因果
