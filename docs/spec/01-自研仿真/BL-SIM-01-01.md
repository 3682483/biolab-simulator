## 2. 学科定位

人教版必修一第 2 章第 1 节。课标要求：说出细胞主要由 C、H、O、N、P、S 等元素构成，认同生物界与非生物界的统一性和差异性。前置知识：元素与化合物的基本概念；后续知识：无机盐、糖类、脂质、蛋白质、核酸。

## 3. 教学目标

1. 能区分大量元素与微量元素，并说明划分依据是**含量**而非作用大小。
2. 能说明细胞与地壳在元素**种类大体相同、含量差异很大**，据此解释统一性与差异性。
3. 能说明 C 被称为"最基本元素"的原因（构成有机物碳链骨架）。
4. 能分别说出鲜重与干重条件下含量最多的前两位元素。

## 4. 知识点解析

必须准确表述：

- 组成细胞的化学元素常见有 20 多种；大量元素为 C、H、O、N、P、S、K、Ca、Mg 等，微量元素为 Fe、Mn、Zn、Cu、B、Mo 等。
- 最基本元素 **C**；基本元素 C、H、O、N；主要元素（占鲜重 97% 以上）C、H、O、N、P、S。
- 鲜重含量最多的是 **O**（因水占 70%–90%）；干重含量最多的是 **C**。
- 微量元素含量少但**作用不可替代**，如 Fe 参与血红蛋白、Mg 参与叶绿素。

常见错误概念：

1. "微量元素作用小"——错，微量元素是含量少，缺乏即致病。
2. 混淆鲜重与干重的元素排序（鲜重 O>C>H>N，干重 C>O>N>H）。
3. 认为细胞与地壳元素种类不同——错，种类大体相同，只是含量差异悬殊。

## 6. 互动素材

- 元素构成数据集（细胞与地壳两套，按物种分支）
- 对数柱状图组件（避免 O、C 与 Mo 等量级差异导致小元素不可见）
- 元素卡片（20+ 张，含名称、符号、类别、代表功能）

## 7. 标注要求

等级 **A2**（编号 + 图例）。标注项：C（最基本元素）、O（鲜重最多）、N、H、P、S、Fe（血红蛋白）、Mg（叶绿素）、I（甲状腺激素）、Ca（骨骼）。每条标注必须带功能，不允许只给名称。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 切换物种（人/玉米/大肠杆菌） | 元素种类保持不变，含量构成随之变化 | 建立"元素种类高度统一、含量差异明显" |
| 拖动含量滑块 | 柱高实时变化，0.01% 分界线标注大量/微量 | 理解分类依据是含量 |
| 切换鲜重/干重 | 柱状图重排序，O 与 C 首位互换 | 消除鲜重干重混淆 |
| 点击任一元素 | 显示存在形式与缺乏症 | 建立"元素—化合物—功能"关联 |
| 查看结论 | 展示统一性/差异性结论与易错点 | 完成归纳 |

## 9. 参数与模型

- 分类阈值：占细胞鲜重 > 0.01% 记为大量元素，≤ 0.01% 记为微量元素（教材口径）
- 鲜重排序（人）：O 65%、C 18%、H 10%、N 3%、Ca 1.5%、P 1.0%
- 干重排序：C 48.4%、O 23.7%、N 12.9%、H 6.6%
- 地壳含量（质量分数）：O 48.6%、Si 26.3%、Al 7.73%、Fe 4.75%、Ca 3.45%

## 10. 三维与可视化规范

等级 **L1**：本实验本质是数据比较，三维无教学增益，禁止为"能用三维"而强行建模。使用矢量图 + 对数柱状图；动效仅用于柱高过渡（≤ 300ms，ease-out），不做无意义的旋转动画。

## 11. 验收标准

- [ ] 切换三种生物时，元素种类不变、含量构成改变
- [ ] 大量/微量元素分界线与教材口径一致，且能说明依据是含量
- [ ] 鲜重与干重切换后，首位元素分别为 O 与 C
- [ ] 任意微量元素的说明中不出现"作用较小"类表述
- [ ] 每个元素卡片均给出"参与构成的化合物 + 缺乏症"至少一项

## 12. 现有实现问题
