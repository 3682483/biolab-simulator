## 2. 学科定位

人教版必修一第 4 章第 1、2 节。课标要求：说明物质进出细胞的方式及其特点，能根据条件判断运输方式。前置：细胞膜结构（BL-SIM-01-04）；后续：细胞呼吸供能、渗透作用、植物吸水与施肥。

## 3. 教学目标

1. 能区分自由扩散、协助扩散、主动运输在**是否需要载体、是否耗能、是否逆浓度**三方面的差异。
2. 能说明通道蛋白与载体蛋白的区别（是否与被转运物结合、是否发生构象变化）。
3. 能判断胞吞、胞吐属于耗能且依赖膜流动性的方式，适用于大分子。
4. 能根据给出的实验条件（加呼吸抑制剂、加载体抑制剂、浓度梯度方向）推断运输方式。

## 4. 知识点解析

必须准确表述：

- 自由扩散：高浓度→低浓度，不需载体、不耗能（O₂、CO₂、H₂O、甘油、乙醇、苯）。
- 协助扩散：高浓度→低浓度，需载体或通道、不耗能（葡萄糖进入红细胞）。
- 主动运输：可逆浓度梯度，需载体、耗能（小肠上皮吸收葡萄糖、氨基酸，K⁺/Na⁺ 泵）。
- 胞吞/胞吐：大分子或颗粒，耗能，依赖膜的流动性（如分泌蛋白、巨噬细胞吞噬）。
- 判断依据的顺序：先看是否耗能，再看是否需载体，最后看浓度方向。

常见错误概念：

1. 认为协助扩散不需要载体（需载体或通道，只是不耗能）。
2. 认为主动运输一定逆浓度（存在顺浓度但耗能的主动运输情形，判断以"耗能+载体"为准）。
3. 认为通道蛋白与被转运物结合（通道不结合，载体结合并变构）。
4. 认为胞吞胞吐不耗能或与膜流动性无关。

## 5. 界面设计

主画布：细胞膜截面 + 物质粒子流；中央为双层膜与三类转运装置（通道、载体、囊泡）。控制区：物质选择（O₂/葡萄糖/K⁺/大分子蛋白）、方式切换、能量开关（加入呼吸抑制剂）、浓度梯度方向。数据区：运输速率、是否耗能、是否需载体、净流向。讲解区：判定决策树。

## 6. 互动素材

磷脂双层截面、通道蛋白（开放孔道）、载体蛋白（构象变化两态）、ATP 供能图标、囊泡形成与融合动画、粒子浓度可视化（密度差）。

## 7. 标注要求

等级 **A3**。标注项：磷脂双分子层、通道蛋白、载体蛋白、ATP、浓度梯度方向、囊泡。载体蛋白需标注"结合—变构—释放"三步；通道蛋白标注"不结合、只开闭"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择 O₂ 与自由扩散 | 粒子沿浓度梯度穿膜，速率与浓度差成正比 | 建立被动运输基线 |
| 选葡萄糖并开启协助扩散 | 需通道/载体，速率出现饱和（载体数量限制） | 理解载体饱和 |
| 切到主动运输 | 粒子逆浓度累积，能量指示器消耗 | 认识耗能特征 |
| 关闭能量供应 | 主动运输停止，协助扩散继续 | 区分"耗能"这一判据 |
| 加入载体抑制剂 | 协助扩散与主动运输均受阻，自由扩散不受影响 | 区分"需载体"判据 |
| 选择大分子蛋白 | 只有胞吞/胞吐可行，囊泡形成 | 建立尺寸判据 |

## 9. 参数与模型

- 自由扩散速率：v = k·ΔC（线性）
- 协助扩散：v = Vmax·C/(Km + C)（米氏型饱和，体现载体数量限制）
- 主动运输：需能量项，能量为 0 时 v = 0；可设最大泵速
- 抑制剂：载体抑制剂使 Vmax → 0；呼吸抑制剂使能量项 → 0

## 10. 三维与可视化规范

等级 **L3**：需要看清载体蛋白构象变化与囊泡形成，二维剪影不足以表达。相机：正视截面，允许 ±30° 侧转以观察膜内通道；材质：膜半透明、蛋白实体；配色：通道蓝、载体紫、ATP 金色脉冲、膜灰绿。

## 11. 验收标准

- [ ] 三种方式的速率曲线形态正确（线性 / 饱和 / 逆梯度累积）
- [ ] 关闭能量后仅主动运输停止
- [ ] 载体抑制剂对自由扩散无影响
- [ ] 载体蛋白显示结合—变构—释放全过程
- [ ] 大分子只能通过胞吞/胞吐且显示耗能
- [ ] 判定题库至少 8 题，每题给出三判据依据
