## 2. 学科定位

人教版必修一第 6 章第 1 节。课标要求：描述有丝分裂各时期的染色体行为与结构变化，说明其保持遗传稳定性的意义。前置：细胞周期；后续：减数分裂、染色体变异、植物组织培养。

## 3. 教学目标

1. 能按顺序描述前期、中期、后期、末期的主要特征（核膜核仁、染色体形态、纺锤体、着丝粒行为）。
2. 能说明中期是观察染色体形态和数目的**最佳时期**（着丝粒排列于赤道板）。
3. 能说明后期着丝粒分裂使染色体数目**暂时加倍**，末期恢复为 2n。
4. 能比较高等植物细胞与动物细胞有丝分裂的差异（纺锤体来源、细胞质分裂方式）。

## 4. 知识点解析

必须准确表述：

| 时期 | 主要特征 |
| --- | --- |
| 间期 | DNA 复制与有关蛋白质合成（染色体呈染色质丝状） |
| 前期 | 核膜、核仁逐渐消失；染色质螺旋缩短变粗成染色体；纺锤体形成；染色体散乱分布 |
| 中期 | 着丝粒排列在赤道板上；染色体形态、数目最清晰 |
| 后期 | 着丝粒分裂，姐妹染色单体分开成两条子染色体，分别移向两极；染色体数目暂时加倍 |
| 末期 | 染色体解螺旋成染色质；核膜、核仁重新出现；纺锤体消失；细胞质分裂 |

- 植物细胞：前期由**细胞两极**发出纺锤丝形成纺锤体；末期在赤道板位置形成**细胞板**，进而形成细胞壁。
- 动物细胞：由**中心体**发出星射线形成纺锤体；末期细胞膜从中部**内陷缢裂**。
- 结果：一个亲代细胞形成两个子细胞，染色体数目与亲代相同（2n），保持遗传性状的稳定性。

常见错误概念：

1. 认为后期染色体数目与中期相同（后期着丝粒分裂，染色体数暂时加倍）。
2. 认为中期染色体数目最多（最多在后期）。
3. 认为植物细胞有中心体（高等植物无中心体）。
4. 混淆"赤道板"（位置概念，非真实结构）与"细胞板"（真实结构，植物特有）。
5. 认为核膜核仁在前期"先解体再出现"（前期消失、末期重现，顺序不可颠倒）。

## 5. 界面设计

主画布：细胞三维剖视，可沿时间轴推进（间期→前期→中期→后期→末期）。控制区：时间轴、植物/动物切换、染色体/纺锤体/核膜/细胞板显隐、计数面板开关。数据区：染色体数、DNA 数、染色单体数实时读数。讲解区：该期特征清单与易错提示。

## 6. 互动素材

染色体三维模型（染色质丝↔染色体两种形态可平滑过渡）、纺锤体（植物两极发出 / 动物中心体星射线）、核膜核仁（可淡出/重现）、细胞板与细胞膜缢裂两套末期动画、赤道板参考平面。

## 7. 标注要求

等级 **A3**。标注项：染色质、染色体、姐妹染色单体、着丝粒、赤道板、纺锤体、中心体（动物）、细胞板（植物）、核膜、核仁。必须区分标注"赤道板（位置）"与"细胞板（结构）"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 推进到前期 | 核膜核仁淡出、染色体显现、纺锤体出现 | 建立前期事件序列 |
| 推进到中期 | 着丝粒对齐赤道板，显示计数：染色体 4 | 理解观察最佳期 |
| 推进到后期 | 着丝粒分裂，染色体数变为 8，向两极移动 | 澄清"暂时加倍" |
| 推进到末期 | 染色体解螺旋、核膜重现、细胞质分裂 | 完成一个周期 |
| 切换动物细胞 | 纺锤体改为中心体星射线，末期为缢裂 | 掌握动植物差异 |
| 计数面板对比 | 三指标随时期变化的曲线 | 形成量化认识 |

## 9. 参数与模型

- 示例染色体数 2n = 4（便于计数）
- 计数规则：间期 S 后 DNA 4、染色体 4、单体 8；后期染色体 8、单体 0；末期子细胞各 4/4/0
- 动画时长比例：前 15%、中 15%、后 25%、末 20%、间期 25%（仅作演示节奏，非真实比例）

## 10. 三维与可视化规范

等级 **L3**：染色体形态变化与纺锤体空间关系必须可旋转观察。相机：默认正视赤道板平面，可旋转至侧视以看清两极分离；材质：染色体实体（同源染色体同色但深浅区分）、纺锤体半透明线；面数 ≤ 10 万，移动端关闭纺锤体半透明。

## 11. 验收标准

- [ ] 四个时期特征与教材一致，顺序正确
- [ ] 后期染色体数暂时加倍并可读出
- [ ] 中期着丝粒对齐赤道板，标注"观察最佳时期"
- [ ] 植物细胞显示细胞板，动物细胞显示缢裂，且纺锤体来源不同
- [ ] 赤道板与细胞板分别标注且说明差异
- [ ] 末期子细胞染色体数与亲代相同
