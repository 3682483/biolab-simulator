## 2. 学科定位

人教版必修一第 5 章第 4 节。课标要求：说明光合作用的过程，探究环境因素对光合作用强度的影响。前置：色素与光反应、酶；后续：光合呼吸综合、农业生产应用、实验设计。

## 3. 教学目标

1. 能说明光照强度、CO₂ 浓度、温度对光合速率的影响方向与饱和特征。
2. 能区分**净光合速率**与**真（总）光合速率**，并用"净 = 真 − 呼吸"进行换算。
3. 能识别光补偿点与光饱和点，并判断饱和后新的限制因子。
4. 能解释"多因子共同限制"现象（单因子饱和后换另一因子仍可提升）。

## 4. 知识点解析

必须准确表述：

- 光照强度：从 0 开始，光合速率先上升后趋于饱和；光照为 0 时仅进行呼吸。
- 光补偿点：光合速率 = 呼吸速率（净光合为 0）；光饱和点：继续增光速率不再上升。
- CO₂ 浓度与温度：温度通过影响酶活性影响速率，存在最适温度。
- 饱和后限制因子切换：光照饱和后，限制因子可能是 CO₂ 浓度或温度。
- 净光合量可用 O₂ 释放量、CO₂ 吸收量或有机物积累量表示；真光合需加上呼吸消耗。

常见错误概念：

1. 认为光照越强光合速率越高（忽略光饱和点）。
2. 把"O₂ 释放量"直接当作真光合速率（实为净光合）。
3. 认为温度只影响呼吸不影响光合（两者均受酶控制）。
4. 认为单一因子饱和后速率无法再提高（提高其他因子仍可提升）。

## 5. 界面设计

主画布：叶肉细胞 + 叶室装置（可测 O₂ 释放/CO₂ 吸收）+ 实时速率曲线。控制区：光照强度、CO₂ 浓度、温度、测量指标（净/真）。数据区：速率读数、光补偿点/饱和点标记、限制因子判定。讲解区：曲线分段解读。

## 6. 互动素材

叶肉细胞模型（叶绿体、类囊体、气孔）、叶室与传感器、速率—光强曲线（含补偿点/饱和点）、速率—CO₂ 曲线、速率—温度曲线、净/真光合对照条。

## 7. 标注要求

等级 **A2**。标注项：叶绿体、类囊体、气孔、光补偿点、光饱和点、净光合速率、真光合速率、呼吸速率。补偿点与饱和点必须在曲线上以可拖动标尺标出。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 光强从 0 递增 | 速率由负（净呼吸）转为正，标记补偿点 | 理解补偿点含义 |
| 继续增光至饱和 | 曲线走平，标记饱和点并提示限制因子 | 建立饱和概念 |
| 切换净/真光合显示 | 同日曲线纵向平移 呼吸速率 值 | 掌握换算关系 |
| 饱和后提高 CO₂ | 速率再上升，曲线抬升 | 认识限制因子切换 |
| 提高温度至过高 | 速率下降（酶变性） | 联系酶特性 |
| 生成影响因素报告 | 汇总三个因子各自的最适区间 | 形成结构 |

## 9. 参数与模型

- 光响应：可用直角双曲线 v = (α·I·Pmax)/(α·I + Pmax) − R
- 补偿点：v = 0 时的 I 值；饱和点：v ≥ 0.95·Pmax 时的 I 值
- CO₂ 响应：米氏型饱和；温度响应：钟形（Topt ≈ 25–30 ℃，与植物种类相关）
- 净光合 = 真光合 − 呼吸；呼吸随温度指数上升（Q10 ≈ 2）

## 10. 三维与可视化规范

等级 **L2**：叶肉细胞与叶室用 2.5D 表现，曲线区为 2D 精确绘制并支持导出数据点。不做三维分子级光反应模拟。

## 11. 验收标准

- [ ] 光强为 0 时速率为负且等于呼吸速率
- [ ] 能读出光补偿点与光饱和点，且数值随 CO₂/温度变化而移动
- [ ] 净/真光合切换时曲线差值等于呼吸速率
- [ ] 饱和后提高其他因子可使速率继续上升
- [ ] 高温导致速率下降并给出"酶变性"解释
- [ ] 曲线支持导出数据点用于课堂计算
