## 2. 学科定位

人教版必修一第 2 章第 5 节、必修二第 3 章第 2 节。课标要求：概述核酸由核苷酸聚合而成，说明 DNA 双螺旋结构的主要特点。前置：核苷酸组成；后续：DNA 复制、转录、翻译。

## 3. 教学目标

1. 能指出脱氧核苷酸与核糖核苷酸在五碳糖与碱基上的差异（2′-H 与 2′-OH；T 与 U）。
2. 能说明 DNA 双螺旋的三项要点：反向平行、外侧磷酸—脱氧核糖交替构成基本骨架、内侧碱基互补配对。
3. 能说明 A—T 之间 2 个氢键、G—C 之间 3 个氢键，并据此判断 GC 含量与稳定性的关系。
4. 能解释 RNA 虽为单链仍可通过链内配对形成局部双链（如 tRNA）。

## 4. 知识点解析

必须准确表述：

- DNA 由两条**反向平行**的脱氧核苷酸链盘旋成双螺旋，外侧为磷酸与脱氧核糖交替连接的基本骨架，内侧碱基对以氢键相连。
- 碱基互补配对原则：A 与 T 配对（2 个氢键），G 与 C 配对（3 个氢键）。
- RNA 通常为单链，五碳糖为核糖，碱基为 A、U、G、C；三类 RNA：mRNA、tRNA、rRNA。

常见错误概念：

1. 认为 DNA 两条链方向相同（同向平行）。
2. 记成 A—T 3 个氢键、G—C 2 个氢键。
3. 认为 RNA 完全不能形成双链结构，无法解释 tRNA 的三叶草形态。
4. 认为"核酸"只有 DNA（遗漏 RNA 也是核酸）。

## 6. 互动素材

- DNA 双螺旋三维模型（20–30 bp 片段，骨架用管状、碱基用色块）
- RNA 单链模型与 tRNA 三叶草折叠形态
- 核苷酸拆解图元：磷酸、脱氧核糖/核糖、碱基三部分可分离高亮
- 氢键可视化：虚线气泡，A—T 两条、G—C 三条

## 7. 标注要求

等级 **A3**。标注项：磷酸（phosphate）、脱氧核糖（deoxyribose）、核糖（ribose）、含氮碱基（nitrogenous base）、氢键（hydrogen bond）、基本骨架（backbone）、反向平行（antiparallel）。差异项用统一高亮色（2′-H / 2′-OH、T / U）在两侧同步标注，便于对照。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 旋转 DNA 模型 | 双螺旋与标注同步旋转，方向箭头显示两条链反向 | 建立反向平行直觉 |
| 点击单条核苷酸 | 拆成磷酸+糖+碱基三部分并高亮 | 理解组成单位 |
| 并排对比糖环 | 2′ 位 —H 与 —OH 高亮差异 | 明确 DNA/RNA 关键区别 |
| 拖拽碱基到配对位 | 正确配对则生成对应数量氢键，错误则提示氢键数不匹配 | 内化配对规则与氢键数 |
| 调节 GC 含量 | 氢键总数与"稳定性"指示条联动 | 理解 GC 与热稳定性 |
| 切换 tRNA 视图 | 单链折叠为三叶草，链内配对高亮 | 修正"RNA 不能配对"误解 |

## 9. 参数与模型

- 氢键数：A—T = 2，G—C = 3
- 稳定性指标：可用经验式 Tm ≈ 64.9 + 41 × (GC 数 − 16.4) / 总碱基数 作定性参考，界面上标注"经验估算，仅供定性理解"
- 模型规模：DNA 片段 ≤ 30 bp；tRNA ≤ 76 nt 简化示意

## 10. 三维与可视化规范

等级 **L3**：必须可自由旋转与局部放大，因为"反向平行"与"内侧/外侧"关系无法由二维图示准确建立。相机：默认斜 30° 俯视，限制极角 15°–165°；材质：骨架磨砂、碱基区分四色（A 绿、T 橙、G 蓝、C 黄，且全站统一）；面数 ≤ 15 万，移动端降级为骨架 + 简化碱基。

## 11. 验收标准

- [ ] 模型上的方向箭头能明确显示两条链反向平行
- [ ] A—T 标注为 2 个氢键、G—C 标注为 3 个氢键
- [ ] 糖环差异（2′-H / 2′-OH）在两侧视图中同时可辨
- [ ] 配对搭建模式中错误配对有明确反馈，不静默通过
- [ ] GC 含量变化时稳定性指示与氢键总数同向变化
- [ ] tRNA 视图能显示链内配对区
