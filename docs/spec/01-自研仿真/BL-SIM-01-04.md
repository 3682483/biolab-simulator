## 2. 学科定位

人教版必修一第 3 章第 1 节。课标要求：概述细胞膜的结构与功能，说明流动镶嵌模型的主要内容。前置：磷脂分子结构；后续：物质跨膜运输、生物膜系统、细胞识别。

## 3. 教学目标

1. 能描述磷脂双分子层是膜的基本骨架，磷脂分子亲水头朝外、疏水尾相对。
2. 能区分蛋白质在膜上的三种位置关系（镶嵌、贯穿、附着），并说明糖被只分布在膜外表面。
3. 能说明结构特点（一定的流动性）与功能特点（选择透过性）的关系。
4. 能解释温度与胆固醇含量对膜流动性的影响方向。

## 4. 知识点解析

必须准确表述：

- 磷脂双分子层构成膜的基本骨架；蛋白质分子以镶嵌、贯穿、附着三种方式分布。
- 糖类与蛋白质结合形成糖蛋白（糖被），位于细胞膜的**外表面**，与细胞识别、免疫、润滑保护有关。
- 动物细胞膜中含胆固醇，具有调节膜流动性的作用；植物细胞膜不含胆固醇（含植物甾醇），教材层面不作扩展要求。
- 膜的结构特点是具有一定的流动性，功能特点是选择透过性。

常见错误概念：

1. 把膜想象为静止的"蛋白质—脂质—蛋白质"三明治结构。
2. 认为糖被在膜内外两侧都有。
3. 认为温度升高流动性一定持续增强（超出范围膜结构会被破坏）。
4. 认为胆固醇只起"降低流动性"作用（其对流动性是**双向调节**）。

## 5. 界面设计

| 区域 | 内容 |
| --- | --- |
| 主画布 | 膜片三维视图（局部剖面），可旋转、可拉近观察单个磷脂 |
| 控制区 | 温度滑块（4–45 ℃）、胆固醇含量（0–40%）、蛋白视图切换（通道/载体/受体/酶） |
| 数据区 | 流动性指数、膜厚度、荧光漂白恢复曲线 |
| 讲解区 | 模型要点与实验证据（人鼠细胞融合、荧光漂白恢复） |

## 6. 互动素材

- 磷脂双分子层三维模型（可用实例化渲染 1–2 万磷脂分子）
- 三类膜蛋白模型：通道蛋白、载体蛋白、受体蛋白
- 糖链/糖被图元（只在外侧）
- FRAP 荧光漂白恢复动画：一束激光使局部荧光淬灭，观察荧光回填速度

## 7. 标注要求

等级 **A3**。标注项：磷脂双分子层（phospholipid bilayer）、亲水头（hydrophilic head）、疏水尾（hydrophobic tail）、膜蛋白（membrane protein）、糖被/糖蛋白（glycocalyx）、胆固醇（cholesterol）。标注需区分膜的内外两侧（外侧标注"细胞外"指示牌），避免糖被标错位置。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 旋转并剖面观察 | 显示双层结构，疏水尾相对排列 | 建立"骨架"概念 |
| 拖动温度滑块 | 磷脂侧向扩散加快，FRAP 回填变快；超过 45 ℃ 提示膜结构受损 | 理解流动性与温度关系 |
| 调节胆固醇 | 低温时减小流动性、高温时限制过度流动 | 理解双向调节 |
| 切换蛋白类型 | 显示通道/载体/受体/酶的位置与功能卡 | 认识蛋白镶嵌方式与功能 |
| 点击糖被 | 高亮并标注"仅位于细胞外表面" | 修正内外不分 |
| 完成"内外判断"小测 | 随机给出结构，判断位于内侧还是外侧 | 强化不对称性 |

## 9. 参数与模型

- 流动性指数（0–100）：以磷脂侧向扩散系数归一化表示，温度项按指数关系简化，胆固醇项以钟形修正（含量 15%–25% 时综合流动性适中）
- 温度边界：< 10 ℃ 提示"膜流动性显著降低"；> 45 ℃ 提示"蛋白质变性、膜结构破坏"
- 性能：磷脂以 InstancedMesh 渲染，单帧更新仅调整实例矩阵

## 10. 三维与可视化规范

等级 **L3**。相机：默认侧视剖面，可环绕 360°，极角限制 10°–170°；材质：磷脂头球面（浅蓝）、尾双链（米黄）、蛋白（紫）、糖链（绿）；面数预算：磷脂实例化不计入三角面，蛋白合计 ≤ 20 万；移动端将磷脂数量降至 1/3 并关闭阴影。

## 11. 验收标准

- [ ] 磷脂双分子层可辨认亲水头朝两侧、疏水尾相对
- [ ] 三类膜蛋白的镶嵌状态可见且与功能卡一致
- [ ] 糖被只出现在膜外侧，内侧无糖被
- [ ] 温度升高时 FRAP 回填速度加快，且存在上限提示
- [ ] 胆固醇对流动性表现为双向调节，而非单向降低
- [ ] 模型旋转时标注不脱锚、不重叠超过 15% 视口
