## 2. 学科定位

人教版必修二第 2 章第 1 节。课标要求：阐明减数分裂的过程与意义，说明配子多样性的来源。前置：有丝分裂、染色体结构；后续：受精作用、遗传规律（分离与自由组合）、染色体变异。

## 3. 教学目标

1. 能按顺序描述减数第一次分裂与第二次分裂各时期的关键事件。
2. 能说明**染色体数目减半发生在减Ⅰ末期**（同源染色体分离），而非减Ⅱ。
3. 能说明联会、四分体、交叉互换发生的时期（减Ⅰ前期）及其意义（基因重组）。
4. 能比较精子形成（均等分裂，1→4）与卵细胞形成（不均等分裂，1→1+3 极体）的差异。

## 4. 知识点解析

必须准确表述：

- 减Ⅰ前期：同源染色体两两配对（**联会**），形成**四分体**；非姐妹染色单体之间可发生**交叉互换**。
- 减Ⅰ中期：同源染色体成对排列在赤道板**两侧**（有丝分裂是着丝粒排在赤道板上）。
- 减Ⅰ后期：同源染色体分离，非同源染色体自由组合；此为基因重组的重要来源。
- 减Ⅰ末期：细胞一分为二，染色体数目减半（2n → n），但每条染色体仍含两条姐妹染色单体。
- 减Ⅱ：无同源染色体；后期着丝粒分裂，姐妹染色单体分开；结果形成 4 个含 n 条染色体的子细胞。
- 精子形成：1 个精原细胞 → 4 个精细胞（均等分裂），经变形为精子。
- 卵细胞形成：1 个卵原细胞 → 1 个卵细胞 + 3 个极体（两次均为不均等分裂）。

常见错误概念：

1. 认为减Ⅱ也存在同源染色体（减Ⅱ细胞中无同源染色体）。
2. 认为染色体减半发生在减Ⅱ（实为减Ⅰ，因同源染色体分离）。
3. 认为交叉互换发生在减Ⅱ或发生在姐妹染色单体之间（发生在减Ⅰ前期的非姐妹染色单体之间）。
4. 认为一个精原细胞可产生 4 种配子（一个精原细胞只产生 2 种、4 个；一个个体可产生 2ⁿ 种）。

## 5. 界面设计

主画布：细胞三维剖视，时间轴推进减Ⅰ（前/中/后/末）与减Ⅱ（前/中/后/末）。控制区：时间轴、精/卵切换、交叉互换开关、同源染色体颜色配对、计数面板。数据区：染色体数、DNA 数、染色单体数、同源染色体对数。讲解区：各期特征与"与有丝分裂的区别"对照。

## 6. 互动素材

同源染色体三维模型（父源/母源配色）、联会与四分体形成动画、交叉互换可视化（片段交换并标记重组点）、纺锤体与两极分离、不均等分裂（卵细胞形成）动画、极体退化示意。

## 7. 标注要求

等级 **A3**。标注项：同源染色体、姐妹染色单体、联会、四分体、交叉互换、赤道板、纺锤体、极体。交叉互换标注需指明"非姐妹染色单体之间"，并标出交换的片段。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 推进至减Ⅰ前期 | 同源染色体配对形成四分体，可开启交叉互换 | 掌握联会与互换 |
| 开启交叉互换 | 非姐妹单体交换片段，重组点高亮 | 理解基因重组来源 |
| 推进至减Ⅰ后期 | 同源染色体分别移向两极，计数显示 n | 明确减半时机 |
| 推进至减Ⅱ后期 | 着丝粒分裂，姐妹单体分开，无同源 | 与有丝分裂对比 |
| 切换卵细胞形成 | 两次不均等分裂，产生 1 卵 + 3 极体 | 掌握性别差异 |
| 对比模式 | 与有丝分裂同期并排显示 | 强化差异记忆 |

## 9. 参数与模型

- 示例染色体数 2n = 4（2 对同源）
- 计数：减Ⅰ前 DNA 4n、染色体 2n、单体 4n；减Ⅰ末 DNA 2n、染色体 n、单体 2n；减Ⅱ末各 n/n/0
- 配子多样性：n 对同源染色体时，一个个体可产生 2ⁿ 种（不考虑互换）

## 10. 三维与可视化规范

等级 **L3**：同源染色体配对与交叉互换必须可旋转观察。相机：正视赤道板，可侧转看两极分离；材质：父源染色体深色、母源浅色，重组片段用第三种颜色标记；面数 ≤ 12 万。

## 11. 验收标准

- [ ] 联会、四分体、交叉互换的时期正确（减Ⅰ前期）
- [ ] 减Ⅰ后期同源染色体分离，染色体数由 2n 变为 n
- [ ] 减Ⅱ细胞明确无同源染色体
- [ ] 精子形成（1→4 均等）与卵细胞形成（1→1+3 极体）对比清晰
- [ ] 交叉互换标注限定"非姐妹染色单体之间"
- [ ] 计数面板在每次分裂后正确更新
