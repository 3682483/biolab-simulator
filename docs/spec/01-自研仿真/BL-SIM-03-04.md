## 2. 学科定位

人教版必修二第 2 章第 1 节。课标要求：说明受精作用的过程与意义，理解减数分裂与受精作用共同维持染色体数目恒定。前置：减数分裂（BL-SIM-03-03）；后续：遗传规律、伴性遗传、染色体变异。

## 3. 教学目标

1. 能说明受精作用是精卵识别、融合形成受精卵的过程，受精卵染色体数为 2n。
2. 能说明减数分裂使染色体减半、受精作用使数目恢复，二者共同维持前后代染色体数目恒定。
3. 能说明配子多样性（非同源染色体自由组合、交叉互换）与受精随机性共同构成后代遗传多样性。
4. 能说明受精卵的核 DNA 父母各半，但细胞质 DNA 几乎全部来自母方。

## 4. 知识点解析

必须准确表述：

- 受精作用：精子与卵细胞相互识别、融合成为受精卵的过程（哺乳动物发生在输卵管）。
- 受精卵中的染色体一半来自父方、一半来自母方，恢复为 2n。
- 减数分裂 + 受精作用的意义：维持生物前后代体细胞染色体数目的恒定，对遗传和变异有重要意义。
- 配子多样性来源：减Ⅰ后期非同源染色体自由组合、减Ⅰ前期交叉互换；再加受精过程中精卵结合的随机性。
- 细胞质遗传物质（线粒体 DNA）主要来自卵细胞，因此细胞质性状表现为母系遗传。

常见错误概念：

1. 认为受精卵中遗传物质父母各占一半（核 DNA 各半，细胞质 DNA 主要来自母方）。
2. 认为受精作用使染色体数目加倍（是从 n 恢复到 2n，非在原有基础上加倍）。
3. 认为受精作用只与染色体数目有关（还产生遗传多样性）。
4. 认为同种生物的所有精子都能与任意卵细胞结合（存在识别特异性）。

## 5. 界面设计

主画布：精卵相遇与融合三维视图（精子穿越放射冠、透明带，精卵膜融合，核融合）。控制区：配子选择（不同染色体组合的精子）、受精开关、计数面板（n / 2n）、母系/父系来源标记。数据区：染色体数、DNA 数、来源占比（核/质）。讲解区：减数分裂 + 受精的闭环示意。

## 6. 互动素材

精子与卵细胞三维模型（可辨染色体组合差异）、受精过程分步动画、染色体来源双色标记（父源/母源）、细胞质中线粒体 DNA 的母系标记、多样性组合示意（2ⁿ 种配子）。

## 7. 标注要求

等级 **A3**。标注项：精子、卵细胞、受精卵、染色体（父源/母源）、细胞核、线粒体 DNA。必须标注"细胞质 DNA 主要来自母方"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择一个精子（不同染色体组合） | 显示该配子的染色体构成 | 理解配子多样性 |
| 启动受精 | 精卵识别、融合、核融合，染色体数显示 n + n → 2n | 掌握数目恢复 |
| 查看来源标记 | 染色体双色各半，线粒体标记为母源 | 区分核遗传与质遗传 |
| 切换不同精子重复受精 | 后代染色体组合不同 | 理解遗传多样性 |
| 关闭"减数分裂"环节 | 提示 2n + n = 3n，说明减半的必要性 | 理解两次过程的互补 |

## 9. 参数与模型

- 示例 2n = 4：配子 n = 2，受精卵 2n = 4
- 配子种类：n 对同源染色体时可形成 2ⁿ 种（不考虑互换）
- 细胞质 DNA 占比：以"几乎全部来自母方"定性表述，不给具体百分比（避免误导）

## 10. 三维与可视化规范

等级 **L3**：精卵形态与融合过程需三维呈现（尺寸差异、穿透层次）。相机：默认侧视，可缩放至膜融合细节；材质：精子头部半透明、卵细胞外层颗粒感；面数 ≤ 8 万。

## 11. 验收标准

- [ ] 受精前后染色体数由 n + n → 2n 正确显示
- [ ] 染色体来源双色各半，线粒体 DNA 标注母源
- [ ] 明确表述"维持前后代染色体数目恒定"
- [ ] 配子多样性来源（自由组合 / 交叉互换 / 受精随机性）齐全
- [ ] 不出现"受精使染色体加倍"的表述
- [ ] 有减数分裂缺失的反证（3n）说明其必要性
