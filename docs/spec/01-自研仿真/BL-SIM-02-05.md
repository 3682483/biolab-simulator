## 2. 学科定位

人教版必修一第 5 章第 3 节。课标要求：说明细胞呼吸的过程、场所与意义，比较有氧呼吸与无氧呼吸。前置：ATP、酶；后续：光合作用、呼吸商、实验探究（酵母菌呼吸方式）。

## 3. 教学目标

1. 能写出有氧呼吸三个阶段各自的场所、反应物与产物。
2. 能说明 O₂ 仅在第三阶段参与、CO₂ 仅在第二阶段产生、H₂O 在第二阶段被消耗且在第三阶段生成。
3. 能计算一分子葡萄糖彻底氧化产生的 ATP 总数与各阶段占比（教材口径）。
4. 能比较有氧呼吸与无氧呼吸（乳酸发酵、酒精发酵）的产物与能量差异。

## 4. 知识点解析

必须准确表述：

- 第一阶段（糖酵解）：**细胞质基质**，葡萄糖 → 2 丙酮酸 + 4[H] + 少量能量（2 ATP）。
- 第二阶段：**线粒体基质**，2 丙酮酸 + 6H₂O → 6CO₂ + 20[H] + 少量能量（2 ATP）。
- 第三阶段：**线粒体内膜**，24[H] + 6O₂ → 12H₂O + 大量能量（约 34 ATP）。
- 总反应式：C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量（教材口径约 38 ATP，能量大部分以热能散失）。
- 无氧呼吸：细胞质基质中，葡萄糖 → 2 乳酸 + 少量能量，或 → 2 酒精 + 2CO₂ + 少量能量；仅第一阶段产生 ATP。

常见错误概念：

1. 认为 CO₂ 在第三阶段产生（实际在第二阶段）。
2. 认为 O₂ 在第二阶段参与（实际只在第三阶段）。
3. 认为水只在第三阶段生成（第二阶段的反应物也含水）。
4. 认为无氧呼吸的两个阶段都产 ATP（只有第一阶段产）。

## 5. 界面设计

主画布：细胞三维剖视（细胞质基质、线粒体基质、线粒体内膜三区）与物质流向。控制区：阶段切换（1/2/3/全部）、氧气开关、呼吸类型（有氧/乳酸发酵/酒精发酵）、[H] 显示开关。数据区：各阶段 ATP、CO₂、H₂O、[H] 收支表。讲解区：反应式与场所对照。

## 6. 互动素材

葡萄糖分子与丙酮酸、[H]、CO₂、O₂、H₂O 粒子；线粒体剖面（外膜、内膜、嵴、基质）；电子传递链简化示意；能量条（ATP 与热能分配）。

## 7. 标注要求

等级 **A3**。标注项：细胞质基质、线粒体基质、线粒体内膜、嵴、葡萄糖、丙酮酸、[H]（NADH）、CO₂、O₂、H₂O、ATP。场所标注必须与反应阶段一一对应，[H] 需注明"还原型辅酶"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 启动阶段一 | 葡萄糖在细胞质基质裂解为丙酮酸并释放 [H] | 建立场所—反应对应 |
| 进入阶段二 | 线粒体基质内加入 H₂O、释放 CO₂ 与 [H] | 纠正"CO₂ 来自第三阶段" |
| 进入阶段三 | 内膜上 [H] 与 O₂ 结合生成 H₂O，ATP 大量增加 | 明确 O₂ 的唯一作用位点 |
| 关闭 O₂ | 阶段三中断，[H] 累积，提示"发酵接管" | 连接无氧呼吸 |
| 切换乳酸发酵 | 产物变为乳酸，ATP 仅来自阶段一 | 比较能量差异 |
| 查看收支表 | 各阶段 ATP/[H]/CO₂/H₂O 汇总 | 形成定量结构 |

## 9. 参数与模型

- ATP 计数（教材口径）：阶段一 2、阶段二 2、阶段三 34，合计约 38
- [H] 计数：阶段一 4、阶段二 20，合计 24，对应 6O₂ → 12H₂O
- 能量分配：约 40% 储存于 ATP，其余以热能散失（定性条显示）
- 无氧呼吸：每分子葡萄糖产 2 ATP（仅阶段一）

## 10. 三维与可视化规范

等级 **L2**：需要三维剖视才能表现"三个阶段发生在不同空间"，但不做原子级模拟。线粒体可旋转，剖切面显示内膜嵴；粒子沿固定路径流动，禁止随机漂移。配色：细胞质基质浅蓝、线粒体基质浅橙、内膜深橙；CO₂ 灰白、O₂ 蓝、[H] 绿、H₂O 浅蓝。

## 11. 验收标准
