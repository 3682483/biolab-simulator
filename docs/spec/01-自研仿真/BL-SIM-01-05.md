## 2. 学科定位

人教版必修一第 3 章第 2、3 节。课标要求：说明主要细胞器的结构和功能，举例说明细胞器之间的分工合作；阐明细胞核的结构与功能。前置：细胞膜；后续：分泌蛋白的合成运输、生物膜系统、细胞核与遗传。

## 3. 教学目标

1. 能说出 8 类主要细胞器的结构特点与功能，并区分动植物细胞特有的细胞器。
2. 能以分泌蛋白为例，说明核糖体、内质网、高尔基体、线粒体、细胞膜的分工合作顺序。
3. 能说明细胞核的结构（核膜、核孔、核仁、染色质）与其功能（控制中心、遗传信息库）。
4. 能判断某结构属于单层膜、双层膜还是无膜。

## 4. 知识点解析

必须准确表述：

- 双层膜细胞器：线粒体、叶绿体；单层膜：内质网、高尔基体、溶酶体、液泡；无膜：核糖体、中心体。
- 植物细胞特有：叶绿体、大液泡、细胞壁（非细胞器）；动物细胞特有（低等植物亦有）：中心体。
- 分泌蛋白路径：核糖体（合成）→ 内质网（加工、折叠）→ 高尔基体（进一步加工、分类包装）→ 囊泡 → 细胞膜（胞吐）。
- 细胞核：核膜（双层，有核孔）、核仁（与某种 RNA 的合成及核糖体的形成有关）、染色质（DNA + 蛋白质）。

常见错误概念：

1. 认为所有细胞都有叶绿体（动物细胞、根尖细胞无）。
2. 认为核糖体只附着在内质网上（游离核糖体同样重要）。
3. 混淆"细胞壁"与细胞膜的功能（细胞壁不是细胞器，全透性）。
4. 认为核孔是"任意大分子通道"（具有选择性，mRNA、蛋白质可过，染色质不出核）。

## 5. 界面设计

| 区域 | 内容 |
| --- | --- |
| 主画布 | 三维细胞全景（植物/动物切换），支持剖面与单细胞器聚焦 |
| 控制区 | 细胞类型切换、剖面开关、细胞器显隐、功能路径追踪 |
| 数据区 | 选中细胞器的膜层数、功能、分布 |

## 6. 互动素材

- 三维细胞模型（动物/植物两套，含细胞核、线粒体、叶绿体、内质网、高尔基体、溶酶体、液泡、核糖体、中心体）
- 细胞器剖面模型（线粒体嵴、叶绿体类囊体、内质网腔）
- 分泌蛋白路径动画（带囊泡运输轨迹）

## 7. 标注要求

等级 **A3**。标注项：细胞膜、细胞质基质、细胞核（核膜/核孔/核仁/染色质）、线粒体、叶绿体、内质网、高尔基体、溶酶体、液泡、核糖体、中心体。每条标注须给"膜层数 + 一句话功能"；标注随模型旋转、缩放、剖面动态重排，剖面后自动隐藏被剖切遮挡的锚点。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 切换动物/植物细胞 | 模型替换，差异结构高亮（叶绿体、大液泡、中心体） | 建立差异认知 |
| 点击任一细胞器 | 镜头推进聚焦，显示结构剖面与功能卡 | 结构与功能相适应 |
| 开启剖面 | 沿指定平面切开，显示内部结构 | 理解"膜包被"与内部构造 |
| 启动分泌蛋白路径 | 依次高亮核糖体→内质网→高尔基体→囊泡→细胞膜 | 建立分工合作顺序 |
| 完成"找不同" | 随机给出结构名，判断属于植物/动物/两者 | 巩固特有结构 |
| 查看细胞核 | 显示核孔选择性通过的示意 | 修正"核孔全通"误解 |

## 9. 参数与模型

- 比例：细胞直径约 20 μm；线粒体长 1–2 μm；核糖体 20 nm（需标注"非等比显示"）
- 剖面：支持 X/Y/Z 三向剖切，剖切后内部结构实体化（不出现空心）
- 路径动画时长：总 8 s，可按 0.5×/1×/2× 调速

## 10. 三维与可视化规范

等级 **L3**。相机：默认斜 45° 全景，支持环绕与缩放（限制最近 0.2 倍细胞直径）；材质：半透明细胞膜（透光 20%）、细胞器实体不透明；配色全局统一（线粒体橙红、叶绿体绿、内质网米黄、高尔基体紫、溶酶体蓝紫）；面数 ≤ 30 万，移动端关闭膜半透明与阴影。
