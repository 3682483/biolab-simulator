## 2. 学科定位

人教版必修一第 5 章第 3 节（拓展计算）。课标要求：能依据气体交换数据推断呼吸底物与呼吸方式。前置：有氧呼吸三阶段、无氧呼吸；后续：光合呼吸综合计算（BL-KS-02-0603）。

## 3. 教学目标

1. 能写出呼吸商定义 RQ = 释放 CO₂ 量 / 吸收 O₂ 量（同温同压同体积）。
2. 能记住典型底物的 RQ：糖类 ≈ 1.0、脂肪 ≈ 0.71、蛋白质 ≈ 0.80、混合膳食 ≈ 0.85。
3. 能通过 RQ 判断主要呼吸底物（RQ 明显小于 1 提示脂肪参与）。
4. 能处理"有氧呼吸 + 酒精发酵共存"的复合情形，用 C 守恒与 O 平衡联立求解。

## 4. 知识点解析

必须准确表述：

- RQ = 释放的 CO₂ 体积 / 吸收的 O₂ 体积（同温同压下）。
- 糖类 C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O，RQ = 6/6 = 1。
- 脂肪分子中 C、H 比例高、含氧少，彻底氧化耗氧更多，故 RQ < 1（约 0.71）。
- 蛋白质 RQ ≈ 0.80。
- 无氧呼吸（酒精发酵）：不消耗 O₂ 但释放 CO₂，当有氧呼吸同时存在时，测得的 RQ 会大于 1（若无氧呼吸单独进行，O₂ 消耗为 0，RQ 在数学上无定义，需说明）。

常见错误概念：

1. 认为 RQ = 1 就一定是"只分解糖类"（可能同时存在"糖类有氧呼吸 + 酒精发酵"，需结合 CO₂ 与 O₂ 差值判断）。
2. 用质量比代替体积比计算 RQ。
3. 忽略无氧呼吸对 CO₂ 总量的额外贡献。
4. 认为脂肪 RQ 大于 1（脂肪含氧少，耗氧多，RQ 反而小于 1）。

## 5. 界面设计

主画布：密闭呼吸室 + 气体传感器（O₂、CO₂ 读数）+ 底物选择面板。控制区：底物类型（糖类/脂肪/蛋白质/混合）、是否叠加酒精发酵、葡萄糖与脂肪比例滑块。数据区：O₂ 消耗、CO₂ 释放、RQ 值、推断结论。讲解区：计算步骤与守恒方程。

## 6. 互动素材

密闭容器与传感器、气体分子流动示意、底物分子结构对比（糖类 vs 脂肪的 O 含量差异）、RQ 分区标尺（0.7 / 0.8 / 1.0 / >1）。

## 7. 标注要求

等级 **A2**。标注项：O₂ 消耗、CO₂ 释放、呼吸室、底物、RQ 标尺刻度。标尺须标注"RQ < 0.8 提示脂肪参与"、"RQ > 1 提示叠加酒精发酵"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择糖类 | 显示 O₂ 6 mol、CO₂ 6 mol，RQ = 1.00 | 建立基准 |
| 选择脂肪 | 耗 O₂ 显著增加，RQ ≈ 0.71 | 理解元素组成影响 |
| 拖动混合比例 | RQ 在 0.71–1.00 之间连续变化 | 掌握定量推断 |
| 叠加酒精发酵 | CO₂ 总量上升、O₂ 不变，RQ > 1 | 理解复合情形 |
| 输入未知样本数据 | 系统反解底物比例 | 训练守恒法求解 |

## 9. 参数与模型

- 糖类：RQ = 1.00；脂肪（三棕榈酸甘油酯）：C₅₁H₉₈O₆ + 72.5 O₂ → 51 CO₂ + 49 H₂O，RQ ≈ 0.70
- 蛋白质：RQ ≈ 0.80；混合膳食：≈ 0.85
- 复合模型：设葡萄糖 x mol、脂肪 y mol，联立
  - CO₂: 6x + 51y + 2z（z 为酒精发酵葡萄糖量）
  - O₂: 6x + 72.5y
- 反解界面须给出解的唯一性与误差容限说明

## 10. 三维与可视化规范

等级 **L1**：以仪表与数值为主，2D 分子结构对比图即可说明"脂肪含氧少、耗氧多"。不做三维呼吸室。

## 11. 验收标准

- [ ] 糖类 RQ 显示 1.00，脂肪约 0.71，蛋白质约 0.80
- [ ] 混合比例变化时 RQ 连续变化且落点正确
- [ ] 叠加酒精发酵后 RQ > 1 且给出原因
- [ ] 未知样本反解结果与设定值一致（误差 ≤ 0.02）
- [ ] 明确说明 RQ 为体积比而非质量比
- [ ] 说明无氧呼吸单独进行时 RQ 无定义

## 12. 现有实现问题

> **现有配置的科学性表述存在问题。**

- `apparatus` 单因子选择器只能"选底物看结论"，没有 O₂/CO₂ 数据与 RQ 计算过程，无法训练计算能力
- note 中"无氧呼吸不耗 O₂ 但产 CO₂（酒精发酵），RQ → ∞"表述不严谨：应为"O₂ 消耗为 0 时 RQ 无定义；与有氧呼吸共存时 RQ > 1"
- 未覆盖脂肪/糖类混合比例的反解，而这正是考试主题型
- 缺少"用质量比计算"的典型错误提示
