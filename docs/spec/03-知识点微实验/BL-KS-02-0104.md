## 2. 学科定位

人教版必修一第 4 章。课标要求：说明大分子进出细胞的方式，区分跨膜运输与非跨膜运输。前置：细胞膜流动性（BL-SIM-01-04）；后续：分泌蛋白、免疫（抗体分泌）、基因表达（mRNA 出核）。

## 3. 教学目标

1. 能说明胞吞、胞吐的对象是大分子或颗粒，依赖膜的流动性并消耗能量。
2. 能说明核孔运输跨核膜、通过核孔复合体、具有选择性。
3. 能判断具体实例属于胞吞、胞吐还是核孔运输。
4. 能说明核孔不允许染色质（DNA）通过，mRNA 与部分蛋白质可通过。

## 4. 知识点解析

必须准确表述：

- 胞吞：大分子附着于膜表面 → 膜内陷形成囊泡 → 进入细胞（如白细胞吞噬细菌、细胞摄取 LDL）。
- 胞吐：囊泡与细胞膜融合 → 内容物排出（如分泌蛋白、抗体、神经递质释放）。
- 两者均消耗能量，且体现膜的流动性；不属于跨膜运输（物质未直接穿过磷脂双分子层）。
- 核孔运输：大分子通过核孔复合体进出细胞核，具有选择性；mRNA、tRNA、核糖体亚基、RNA 聚合酶等可通行，染色质不出核。

常见错误概念：

1. 认为胞吞胞吐不耗能（耗能，且依赖膜流动性）。
2. 认为核孔是"自由通道"，任何大分子都能通过（染色质不通过）。
3. 把"分泌蛋白排出细胞"当作跨膜运输（实为胞吐）。
4. 认为胞吞胞吐只发生在单细胞生物（多细胞生物的白细胞、小肠上皮同样如此）。

## 5. 界面设计

主画布：左侧细胞膜（囊泡形成/融合），右侧核膜（核孔复合体）。控制区：实例卡片库、三个分类桶、判定模式。数据区：每类的耗能/是否跨膜/通行物质清单。讲解区：三类运输对照表。

## 6. 互动素材

膜内陷成囊泡动画、囊泡与膜融合动画、核孔复合体截面（通道 + 选择性）、实例图标（白细胞、抗体、mRNA、LDL）。

## 7. 标注要求

等级 **A2**。标注项：细胞膜、囊泡、核膜、核孔复合体、mRNA、分泌蛋白。核孔须标注"选择性"，并标注"染色质不出核"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 拖拽实例卡片到三个桶 | 正确入桶并显示对应动画；错误给出机制差异 | 建立分类依据 |
| 点击"耗能"开关 | 胞吞胞吐停止，核孔运输不受影响（不直接耗 ATP） | 区分能量依赖 |
| 点击核孔 | 高亮可通过/不可通过的物质 | 理解选择性 |
| 完成判定小测 | 给出新实例（如"胰岛素分泌"）要求归类 | 迁移应用 |

## 9. 参数与模型

- 囊泡直径示意 50–200 nm；核孔复合体直径约 120 nm（示意，需标注非等比）
- 分类判定：错误时必须说明"是否跨膜 / 是否耗能 / 通行对象尺寸与选择性"三点之一

## 10. 三维与可视化规范

等级 **L2**：囊泡形成与融合需要空间表达，用可局部旋转的 2.5D 膜片；核孔用剖面示意。分类交互本身为 2D。

## 11. 验收标准

- [ ] 三类各至少 2 个实例，判定正确
- [ ] 明确标注胞吞胞吐耗能且依赖膜流动性
- [ ] 核孔标注"选择性"与"染色质不出核"
- [ ] 错误分类时给出机制层面的差异说明
- [ ] 不把胞吐表述为"跨膜运输"

## 12. 现有实现问题

> 现有 `classify` 配置内容基本正确。

- 分类游戏验证的是"记住例子"，未呈现囊泡形成/融合与核孔选择性的机制，学生仍可能按关键词记忆
- 未体现"是否跨膜"这一本质差异（胞吞胞吐不是跨膜运输）
- 核孔选择性只在一句 note 中出现，无交互验证
