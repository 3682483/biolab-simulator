## 2. 学科定位

人教版必修二第 5 章。课标要求：说明染色体数目异常的原因，解释 21 三体综合征等实例。前置：减数分裂、染色体变异；后续：人类遗传病、遗传咨询。

## 3. 教学目标

1. 能说明减Ⅰ异常（同源染色体未分离）与减Ⅱ异常（姐妹染色单体未分离）的区别。
2. 能根据配子或子代基因型/染色体组成反推异常发生的时期。
3. 能说明 21 三体综合征多数源于**减Ⅰ**（母方同源染色体不分离），少数源于减Ⅱ。
4. 能说明只有生殖细胞的分裂异常才可能遗传给后代。

## 4. 知识点解析

必须准确表述：

| 异常时期 | 机制 | 配子特征 | 子代典型 |
| --- | --- | --- | --- |
| 减Ⅰ异常 | 同源染色体未分离，移向同一极 | 配子含**一对同源染色体**（n+1）或缺失（n−1） | 三体/单体，如 21 三体（多数） |
| 减Ⅱ异常 | 姐妹染色单体未分离 | 配子含**两条相同的染色体**（来源同一亲本） | 三体/单体（少数） |
| 有丝分裂异常 | 着丝粒不分裂或胞质分裂失败 | 体细胞染色体数目加倍（如四倍体） | 不遗传给后代（体细胞变异） |

判别钥匙：

- 配子中**出现成对的同源染色体** → 减Ⅰ异常
- 配子中**出现两条完全相同的染色体**（同一亲本的姐妹染色单体）→ 减Ⅱ异常
- 体细胞中染色体成倍增加 → 有丝分裂异常（如秋水仙素处理）

关于 21 三体：约 95% 由母方减Ⅰ同源染色体不分离引起，约 5% 由减Ⅱ或父方异常引起；因此"21 三体一律等于减Ⅱ异常"的表述是错误的。

常见错误概念：

1. 认为 21 三体综合征一定是减Ⅱ异常（多数为减Ⅰ）。
2. 认为体细胞染色体加倍可遗传给后代（一般不通过配子传递）。
3. 混淆"同源染色体未分离"与"姐妹染色单体未分离"的判别依据。
4. 认为 47,XXY 只能来自母方（也可能来自父方减Ⅰ）。

## 5. 界面设计

主画布：分裂过程回溯图（减Ⅰ/减Ⅱ两条路径）+ 异常发生点标记。控制区：异常类型选择（减Ⅰ/减Ⅱ/有丝）、异常染色体指定、观察配子与子代。数据区：配子染色体组成、子代核型、发生率说明。讲解区：判别三问与反推步骤。

## 6. 互动素材

染色体分离动画（可注入"不分离"故障）、配子染色体组成卡、核型图（47,XXY / 47,+21）、判别流程图。

## 7. 标注要求

等级 **A2**。标注项：同源染色体、姐妹染色单体、着丝粒、配子、核型。必须标注"同源未分离→减Ⅰ"与"姐妹未分离→减Ⅱ"的对应。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 在减Ⅰ注入"同源不分离" | 配子出现一对同源染色体 | 掌握减Ⅰ特征 |
| 在减Ⅱ注入"着丝粒不分裂" | 配子出现两条相同染色体 | 掌握减Ⅱ特征 |
| 选择 X 射线处理幼苗 | 体细胞染色体加倍，标注"不遗传" | 区分体细胞变异 |
| 反推练习：给出 47,XXY | 要求判断来源并给出两种可能 | 训练多解思维 |
| 反推练习：给出 47,+21 | 要求说明"多数为减Ⅰ" | 纠正单一归因 |

## 9. 参数与模型

- 示例 2n = 4；异常配子染色体数 n+1 = 3 或 n−1 = 1
- 21 三体的来源比例：母方减Ⅰ ≈ 95%，其余 ≈ 5%（教材拓展，界面标注"约"）
- 反推题须允许"存在多种可能"的答案，并按证据强度排序

## 12. 现有实现问题

> **存在科学性错误，P0 必修。**

- 卡片"21 三体综合征（多余的第 21 号染色体）→ 减Ⅱ异常（姐妹未分离）"是**错误归因**：临床上约 95% 的 21 三体源于母方减Ⅰ同源染色体不分离，必须改为"多数为减Ⅰ异常，少数为减Ⅱ"
- 三桶分类只能二选一，无法表达"同一病例存在多种可能"的临床实际
- 未包含 47,XXY 的父方/母方两种来源，学生对"多解"缺乏训练
