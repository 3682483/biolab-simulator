## 2. 学科定位

人教版必修一第 2 章第 2 节。课标要求：举例说明无机盐在细胞中的存在形式与作用。前置：细胞中的元素；后续：渗透压、酸碱平衡、神经兴奋性、光合色素。

## 3. 教学目标

1. 能说出无机盐的两种存在形式：离子形式与化合物形式。
2. 能举例说明无机盐参与构成重要化合物（Fe—血红蛋白、Mg—叶绿素、I—甲状腺激素、P—磷脂/ATP/核酸、Ca—骨骼牙齿）。
3. 能说明离子态无机盐维持渗透压、酸碱平衡与细胞兴奋性的作用。
4. 能解释缺铁性贫血、地方性甲状腺肿、抽搐、佝偻病的成因。

## 4. 知识点解析

必须准确表述：

- 无机盐在细胞中含量很少（占鲜重 1%–1.5%），多数以**离子**形式存在，少数以**化合物**形式存在。
- 离子态功能：维持细胞和生物体的生命活动（如 Ca²⁺ 维持肌肉兴奋性）、维持渗透压与酸碱平衡。
- 化合物态功能：构成细胞内某些复杂化合物的重要组成部分。
- 缺铁 → 血红蛋白合成受阻 → 缺铁性贫血；缺碘 → 甲状腺激素合成受阻 → 地方性甲状腺肿；血钙过低 → 抽搐；儿童缺钙 → 佝偻病。

常见错误概念：

1. 认为无机盐只以离子形式存在（Fe、Mg、I 等参与构成化合物）。
2. 把"含量少"等同于"作用小"。
3. 认为补钙越多越好（吸收需要维生素 D 参与，过量亦有害）。

## 7. 标注要求

等级 **A2**（编号 + 图例）。标注项：Fe²⁺（血红蛋白）、Mg²⁺（叶绿素）、I（甲状腺激素）、P（磷脂/ATP/核酸）、Ca²⁺（骨骼牙齿、肌肉兴奋性）、Na⁺/K⁺（渗透压与兴奋性）。每条须给"存在形式 + 化合物 + 缺乏症"三项信息，不允许只给名称。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择一种元素 | 细胞剖面相应热点区高亮，右侧卡片显示存在形式与化合物 | 建立"元素—化合物—部位"联系 |
| 点击"缺乏模拟" | 显示对应缺乏症与典型人群 | 建立因果链 |
| 切换至离子态示例 | 显示 Na⁺/K⁺ 对渗透压与兴奋性的影响 | 补充"非构成型"功能 |
| 归纳作答 | 拖拽功能卡至"构成材料/维持稳态"两栏 | 形成二分结构 |

## 9. 参数与模型

- 无机盐占细胞鲜重比例：1%–1.5%（界面标注）
- 缺铁性贫血判定：血红蛋白合成不足，与铁摄入量正相关（定性）
- 不做定量动力学，只做定性因果映射（微实验定位决定）

## 10. 三维与可视化规范

等级 **L1**：以矢量剖面 + 卡片为主，不建三维模型。若后续升级，仅细胞剖面可做 2.5D（L2），热点区仍以矢量叠加，避免"三维空壳点击区"。
