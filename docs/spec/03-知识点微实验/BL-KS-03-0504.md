## 2. 学科定位

人教版必修一第 6 章第 3 节。课标要求：说明癌细胞的主要特征与致癌因子，简述癌变机理。前置：细胞周期、细胞分化；后续：基因突变（模块六）、免疫监视（模块七）。

## 3. 教学目标

1. 能列举癌细胞的三个主要特征（无限增殖、形态结构改变、表面糖蛋白减少易转移）。
2. 能区分三类致癌因子（物理、化学、生物）并各举一例。
3. 能说明癌变是原癌基因与抑癌基因发生突变累积的结果。
4. 能说明癌细胞在免疫监视下可被清除，免疫功能低下时风险升高。

## 4. 知识点解析

必须准确表述：

| 维度 | 内容 |
| --- | --- |
| 癌细胞特征 | 能无限增殖（不受接触抑制）；形态结构显著改变（核大、球形）；细胞表面糖蛋白等物质减少，黏着性降低，易分散转移 |
| 致癌因子 | 物理（紫外线、X 射线、电离辐射）、化学（黄曲霉素、亚硝胺、苯）、生物（EB 病毒、乙肝病毒、HPV） |
| 癌变机理 | 原癌基因（促进细胞正常生长分裂）与抑癌基因（抑制异常增殖）发生突变并累积；二者均为正常基因，不是"外来基因" |
| 免疫关系 | 免疫系统具有监控清除癌细胞的功能；免疫监视功能低下时易患肿瘤 |

常见错误概念：

1. 认为癌细胞是"外来细胞"（源于自身细胞基因突变）。
2. 认为原癌基因是"坏的基因"（正常基因，突变后活性过强才致癌）。
3. 认为癌变由单一突变完成（多基因突变累积、多阶段过程）。
4. 认为抑癌基因突变后活性增强（是功能丧失）。
5. 认为癌变只由化学因子引起（三类因子并存）。

## 5. 界面设计

主画布：正常细胞 → 突变累积 → 癌细胞 → 侵袭转移的四阶段演进。控制区：致癌因子选择、突变次数设定、免疫监视开关、观察层级（细胞/基因/群体）。数据区：增殖速率、黏着性、基因突变计数。讲解区：双基因失灵的"油门+刹车"比喻。

## 6. 互动素材

细胞形态对比（正常 vs 癌变：核大、形态不规则）、无限增殖曲线、糖蛋白减少与细胞分散动画、三类致癌因子图标、免疫细胞识别癌细胞示意。

## 7. 标注要求

等级 **A2**。标注项：原癌基因、抑癌基因、糖蛋白、细胞核、致癌因子（三类）、免疫细胞。必须标注"原癌基因与抑癌基因都是正常基因"。

- 不给出具体发病率数字，避免误导

## 12. 现有实现问题

> 现有配置的卡片内容基本正确，但分类维度存在设计问题。

- 三个桶分别是"癌细胞特征 / 致癌因子 / 癌变机理"，**不是同一维度的分类**（特征、原因、机制），作为"分类挑战"会把不同类型的信息混在一起，建议改为"三列归类"（信息卡归入三个信息栏）而非"分类判断"
- 未体现"多基因突变累积"这一核心机制，学生易理解为一次突变即癌变
- 未与免疫监视联系，遗漏"免疫系统可清除癌细胞"的知识点衔接
