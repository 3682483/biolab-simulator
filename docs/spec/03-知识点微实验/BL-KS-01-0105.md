## 2. 学科定位

人教版必修一第 2 章第 3 节。课标要求：概述糖类与脂质的种类与作用。前置：细胞中的化合物；后续：生物膜结构（磷脂）、储能与保温、激素调节（固醇类激素）。

## 3. 教学目标

1. 能区分脂肪、磷脂、固醇三类脂质的组成与功能。
2. 能说明脂肪是细胞内良好的储能物质（1 g 脂肪氧化释能约 39 kJ，高于糖类）。
3. 能说明磷脂是构成生物膜的基本骨架。
4. 能举例说明固醇的三种代表物质及其作用（胆固醇、性激素、维生素 D）。

## 4. 知识点解析

必须准确表述：

- 脂质由 C、H、O 组成，部分含 N、P（如磷脂）；脂质不溶于水，易溶于有机溶剂。
- 脂肪：细胞内良好的储能物质，还有保温、缓冲和减压作用。
- 磷脂：构成细胞膜和细胞器膜的重要成分（双分子层骨架）。
- 固醇：胆固醇（动物细胞膜成分、参与脂质运输）、性激素（促进生殖器官发育与生殖细胞形成）、维生素 D（促进肠道对 Ca、P 的吸收）。
- 脂肪的 C、H 比例高于糖类，故氧化分解时耗氧更多、释放能量更多。

常见错误概念：

1. 把"脂质"等同于"脂肪"（脂质还包括磷脂与固醇）。
2. 认为胆固醇只有害处（是细胞膜成分与激素合成前体）。
3. 认为脂肪与糖类氧化释能相同（同质量脂肪约为糖类两倍以上）。
4. 认为磷脂只含 C、H、O（磷脂含 P，部分含 N）。

## 7. 标注要求

等级 **A2**。标注项：甘油、脂肪酸、磷酸基团、亲水头、疏水尾、四环骨架、固醇类代表物质。标注需强调磷脂的"磷酸基团"（解释其亲水性来源），避免学生误认为磷脂仅由脂肪酸构成。

## 9. 参数与模型

- 释能数据：脂肪约 39 kJ/g，糖类约 17 kJ/g（教材通用口径，需标注"约"）
- 分类判定：卡片 bucket 与目标桶不一致时，必须给出"差异点"提示，而非仅判错

## 10. 三维与可视化规范

等级 **L1**：分子结构用矢量示意图（2D 化学结构式最准确，三维球棍模型反而增加认知负担）。磷脂双分子层排布可做 2.5D 层叠示意，但不建真三维。

## 11. 验收标准

- [ ] 三类脂质各至少 2 张卡片，分类判定正确
- [ ] 脂肪释能约 39 kJ/g 且与糖类对比可见
- [ ] 磷脂明确标注"含磷酸基团"与"膜骨架"功能
- [ ] 固醇三种代表物齐全（胆固醇、性激素、维生素 D）

- [ ] 不出现"脂质=脂肪"的表述

## 12. 现有实现问题

> 现有 `classify` 配置内容较完整，主要问题是形态与深度。

- 分类游戏只能判断"归哪类"，无法体现结构差异，学生仍可能靠关键词记忆
- 未涉及脂肪与糖类的释能定量对比（注册内容中仅一句 note）
- 缺少"磷脂→细胞膜"的前后衔接，知识点孤立
