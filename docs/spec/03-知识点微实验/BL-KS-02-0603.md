## 2. 学科定位

人教版必修一第 5 章综合应用。课标要求：能依据曲线与气体数据完成光合与呼吸的定量计算。前置：光合过程（BL-SIM-02-06）、呼吸三阶段；后续：光合呼吸实验题、农业生产应用。

## 3. 教学目标

1. 能正确使用核心关系：**净光合速率 = 真（总）光合速率 − 呼吸速率**。
2. 能通过"黑暗条件"测得呼吸速率，并据此把净光合曲线换算为真光合曲线。
3. 能计算一昼夜有机物积累量 = 白天净合成量 − 夜间呼吸消耗量。
4. 能识别光补偿点、光饱和点，并处理"超过饱和后改变其他因子"的情形。

## 4. 知识点解析

必须准确表述：

- 净（表观）光合速率：以 O₂ 释放量、CO₂ 吸收量或有机物积累量表示，是**表观**值。
- 真（总）光合速率 = 净光合 + 呼吸速率。
- 黑暗条件下测得的值即呼吸速率（不能为负值，方向定义为消耗）。
- 一昼夜积累量 = Σ（白天净光合 × 光照时长）− Σ（夜间呼吸 × 黑暗时长）；若净光合为负则计为消耗。
- 光补偿点：净光合 = 0；光饱和点：真光合不再随光强上升。

常见错误概念：

1. 把 O₂ 释放量当作真光合（实为净光合）。
2. 计算昼夜积累时只算白天净合成，忽略夜间呼吸消耗。
3. 认为呼吸速率随光强变化（光照对呼吸速率基本无直接影响，温度才是主因）。
4. 用"CO₂ 吸收量"与"CO₂ 固定量"混用（前者为净值，后者为总值）。

## 5. 界面设计

主画布：双曲线图（真光合、净光合）+ 光照/黑暗时间轴。控制区：光强、温度、光照时长与黑暗时长、呼吸速率设定。数据区：真/净速率读数、昼夜积累量实时计算、补偿点/饱和点坐标。讲解区：换算步骤与公式推导。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 关闭光照 | 净光合为负、数值等于呼吸速率 | 掌握"黑暗测呼吸" |
| 调光强至净光合 = 0 | 标出光补偿点坐标 | 理解补偿点 |
| 切换显示真光合 | 曲线整体上移呼吸速率值 | 掌握换算 |
| 设置昼 14 h / 夜 10 h | 实时计算一昼夜积累量 | 处理时间积分 |
| 提高温度 | 呼吸速率上升、净光合下降 | 联系温度效应 |
| 输入未知气体数据 | 反算真光合与呼吸 | 迁移计算 |

## 9. 参数与模型

- 净光合曲线：v_net = (α·I·Pmax)/(α·I + Pmax) − R，R 为呼吸速率
- 真光合：v_total = v_net + R
- 昼夜积累：A = v_net(avg)·t_day − R·t_night（简化用恒定光强；若为变化光强则积分）
- 判定阈值：|计算值 − 期望值| ≤ 0.05 视为正确

## 10. 三维与可视化规范
