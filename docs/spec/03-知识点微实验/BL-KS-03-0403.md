## 2. 学科定位

人教版必修二第 2 章。课标要求：说明减数分裂产生配子的多样性，能计算配子种类。前置：减数分裂、非同源染色体自由组合；后续：分离定律、自由组合定律、遗传概率计算。

## 3. 教学目标

1. 能区分三类主语：一个个体 / 一个精原细胞 / 一个卵原细胞，并给出对应的配子种类数。
2. 能说明 n 对同源染色体时，一个个体可产生 **2ⁿ** 种配子（不考虑交叉互换）。
3. 能说明一个精原细胞产生 **2 种**（共 4 个）配子，一个卵原细胞只产生 **1 种**（1 个）配子。
4. 能说明交叉互换会显著增加配子种类（不考虑互换的 2ⁿ 为下限）。

## 4. 知识点解析

必须准确表述：

| 主语 | 配子种类 | 数量 |
| --- | --- | --- |
| 一个个体（一种生物） | 2ⁿ（n 对同源，不考虑互换） | 大量 |
| 一个精原细胞 | **2 种** | 4 个（每种 2 个） |
| 一个卵原细胞 | **1 种** | 1 个（+3 极体） |

- 2ⁿ 的来源：减Ⅰ后期非同源染色体自由组合。
- 交叉互换：使同一对同源染色体的非姐妹染色单体交换片段，实际配子种类远多于 2ⁿ。
- 审题关键在主语的"一个"与"一种生物"之别。

常见错误概念：

1. 把"一个精原细胞产生 2ⁿ 种"（实为 2 种）。
2. 把"一个个体产生 2 种"（实为 2ⁿ 种）。
3. 认为交叉互换不改变配子种类（会显著增加）。
4. 认为一个卵原细胞产生 4 种配子（只产生 1 个卵细胞）。

## 5. 界面设计

主画布：染色体组合示意（n 对同源染色体，父源/母源双色）+ 配子产物列表（可展开为 2ⁿ 种）。控制区：同源染色体对数 n（1–8）、主语切换（个体/一个精原细胞/一个卵原细胞）、交叉互换开关。数据区：理论种类数、实际产物、计算式。讲解区：审题提示与公式推导。

## 6. 互动素材

染色体双色模型、自由组合分支图（2ⁿ 种组合树）、精原细胞 4 个产物示意、卵原细胞 1 卵 + 3 极体示意、交叉互换前后种类对比。

## 7. 标注要求

等级 **A2**。标注项：同源染色体、父源/母源、次级性母细胞、配子、极体。需标注"主语不同，结论不同"的提示牌。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 设 n = 2 并选"个体" | 显示 4 种配子组合树 | 理解 2ⁿ |
| 切换"一个精原细胞" | 产物收敛为 2 种、共 4 个 | 纠正主语混淆 |
| 切换"一个卵原细胞" | 产物为 1 个卵细胞 + 3 极体 | 掌握数量差异 |
| 开启交叉互换 | 种类数超出 2ⁿ，提示"下限变为上限" | 理解重组的贡献 |
| 完成主语判断小测 | 给出题干要求判断种类并说明理由 | 迁移审题能力 |

## 9. 参数与模型

- 个体：种类 = 2ⁿ（n ≤ 8，避免组合爆炸）
- 一个精原细胞：固定 2 种、4 个
- 一个卵原细胞：固定 1 种、1 个
- 交叉互换：种类数 > 2ⁿ，界面用"≥ 2ⁿ"表述，不给具体数值

## 10. 三维与可视化规范

等级 **L1**：组合树与产物列表用 2D 表达最清晰。染色体可用简单三维模型转动以看清父源/母源，但不作为必需。

## 11. 验收标准

- [ ] 三类主语的结论均正确（2ⁿ / 2 种 / 1 种）
- [ ] 组合树随 n 变化正确展开
- [ ] 交叉互换后明确"种类增加，2ⁿ 不再是上限"
- [ ] 小测包含主语陷阱题（"一个"vs"一种"）
- [ ] 不出现"一个精原细胞产生 2ⁿ 种"的表述

## 12. 现有实现问题

> 现有 `inquiry` 配置已区分两类曲线，方向正确但仍有缺陷。

- 只对比"个体"与"一个原始生殖细胞"，未区分精原细胞与卵原细胞（2 种 vs 1 种）
- 未包含交叉互换，学生可能把 2ⁿ 当作上限
- 曲线形式弱化了"主语决定结论"这一审题要点，缺少陷阱题训练
