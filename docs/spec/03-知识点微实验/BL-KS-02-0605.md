## 2. 学科定位

人教版必修一第 5 章实验综合。课标要求：设计并分析测定光合速率与呼吸速率的装置。前置：光合与呼吸过程、气体交换；后续：模块十实验探究（BL-KS-10-*）。

## 3. 教学目标

1. 能说明"液滴移动法"装置中，不同吸收液对应测定的是 O₂ 变化还是 CO₂ 变化。
2. 能根据液滴移动方向判断净光合与呼吸的相对强弱。
3. 能说明半叶法、叶片上浮法（打孔抽真空）的原理与适用场景。
4. 能指出装置中必须设置对照（死叶/遮光/空白）并说明原因。

## 4. 知识点解析

必须准确表述：

- 液滴移动法：密闭容器 + 毛细管液滴。
  - 用 **NaHCO₃ 溶液**（维持 CO₂ 稳定）→ 气压变化由 O₂ 引起 → 液滴移动反映**净光合速率**。
  - 用 **NaOH 溶液**（吸收 CO₂）→ 气体减少量反映 **O₂ 消耗** → 测定呼吸速率（需遮光）。
  - 用 **清水**（不吸收）→ 液滴移动由 CO₂ 与 O₂ 差值决定，含义复杂，需谨慎解读。
- 半叶法：同一叶片一半遮光、一半曝光，烘干称重差 → 光合合成有机物量（需校正呼吸）。
- 叶片上浮法：叶圆片抽真空后沉于水中，光合产 O₂ 使其上浮，以上浮数量/时间衡量光合速率。
- 必须设置对照：遮光组（测呼吸）、死叶片组（排除物理因素）、温度与气压平衡。

常见错误概念：

1. 认为液滴移动量直接等于真光合速率（含呼吸，且与溶液类型有关）。
2. 认为任何溶液下液滴右移都表示光合 > 呼吸（需看溶液吸收何种气体）。
3. 忽略温度变化引起的气体体积变化（必须设对照或恒温）。
4. 认为半叶法无需校正呼吸。

## 5. 界面设计

主画布：装置图（密闭容器、植物、毛细管液滴、光源、遮光罩）+ 液滴位置实时变化。控制区：溶液类型（NaHCO₃ / NaOH / 清水）、光照/遮光、温度、对照开关。数据区：液滴移动方向与距离、换算后的净光合或呼吸速率。讲解区：装置—指标对应表。

## 6. 互动素材

装置矢量/2.5D 图、液滴动画、气体分子进出示意、半叶法叶片示意（半遮光）、叶圆片上浮动画。

## 7. 标注要求

等级 **A2**。标注项：密闭容器、NaHCO₃ 溶液、NaOH 溶液、毛细管液滴、光源、遮光罩、叶圆片。溶液标注须写明"吸收/维持何种气体"，这是解读液滴方向的前提。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选 NaHCO₃ + 光照 | 液滴向容器内移动（O₂ 增加） | 建立"测净光合" |
| 选 NaOH + 遮光 | 液滴向容器内移动（O₂ 被消耗） | 建立"测呼吸" |
| 同样条件切换溶液 | 液滴方向/幅度改变，提示指标含义变化 | 破除"移动=光合" |
| 开启温度波动 | 出现与光合无关的液滴漂移，提示需恒温/对照 | 理解对照必要性 |
| 切换半叶法 | 显示遮光与曝光半叶干重差 | 掌握另一种方法 |
| 作答"该装置测什么" | 依据溶液与光照作答并给出解析 | 迁移判断 |

## 9. 参数与模型

- 液滴移动距离 ∝ 气体体积变化量（线性，需标注"示意"）
- NaHCO₃ 条件下：ΔV ≈ O₂ 净释放量
- NaOH + 遮光条件下：ΔV ≈ O₂ 消耗量（呼吸）
- 温度扰动模型：每 ±1 ℃ 引起约 0.3% 体积变化（用于演示对照必要性）

## 10. 三维与可视化规范

等级 **L2**：装置用 2.5D 呈现以体现密闭性与液滴位置，气体交换用粒子层表示。不做三维分子模拟。

## 11. 验收标准

- [ ] 三种溶液对应的测量指标标注正确
- [ ] 液滴方向与净光合/呼吸的对应关系正确
- [ ] 温度扰动可导致非光合性漂移，并有对照提示
- [ ] 半叶法、叶圆片法的原理与适用场景说明正确
- [ ] 回答"装置测什么"时必须给出溶液与光照两条依据

## 12. 现有实现问题

> 现有 `apparatus` 配置仅两个因子（光照 × NaHCO₃），结论为文字。

- 未包含 NaOH 溶液测呼吸的经典组合，学生无法理解"同一装置换溶液即换指标"
- 无液滴移动的可视化与数值，缺少从现象到结论的推理链
- 未涉及温度/气压对照，容易形成"液滴移动=光合"的错误理解
