## 2. 学科定位

人教版必修一第 5 章（拓展）。课标要求：说明细胞呼吸与光合作用中还原型辅酶的作用。前置：细胞呼吸三阶段；后续：光合作用光反应与暗反应、代谢网络。

## 3. 教学目标

1. 能说明辅酶是小分子有机物，与酶蛋白结合并传递电子、原子或基团。
2. 能区分 NAD⁺（辅酶Ⅰ）、NADP⁺（辅酶Ⅱ）、FAD（黄素腺嘌呤二核苷酸，属辅基）与 CoA 的结构与功能。
3. 能说明 NADH 主要来自呼吸作用、NADPH 主要来自光合作用光反应，二者功能不同。
4. 能说明维生素 B 族是许多辅酶的前体，缺乏会导致代谢紊乱。

## 4. 知识点解析

必须准确表述：

| 辅酶 | 化学本质 | 主要功能 |
| --- | --- | --- |
| NAD⁺（辅酶Ⅰ） | 烟酰胺腺嘌呤二核苷酸，含维生素 B₃（烟酸） | 呼吸作用中接受脱氢，生成 NADH，作为 [H] 载体 |
| NADP⁺（辅酶Ⅱ） | 烟酰胺腺嘌呤二核苷酸磷酸 | 光合作用光反应中接受电子与 H⁺，生成 NADPH 用于暗反应还原 C₃ |
| FAD | 黄素腺嘌呤二核苷酸，含维生素 B₂（核黄素），**属辅基**（与酶蛋白共价结合） | 呼吸链与三羧酸循环中传递氢 |
| CoA | 泛酸衍生物 | 转移乙酰基，生成乙酰 CoA，是糖、脂、蛋白质代谢的枢纽 |

常见错误概念：

1. **把 FAD 说成"辅酶Ⅱ"**——错。辅酶Ⅱ 是 NADP⁺；FAD 是黄素腺嘌呤二核苷酸，通常作为辅基。
2. 认为 NADH 与 NADPH 可以互换使用（前者服务呼吸产能，后者服务光合还原）。
3. 认为辅酶本身是蛋白质（辅酶是小分子有机物，需与酶蛋白结合才有活性）。
4. 认为 CoA 是递氢体（CoA 转移乙酰基，不是 [H] 载体）。

## 7. 标注要求

等级 **A2**。标注项：NAD⁺、NADH、NADP⁺、NADPH、FAD、FADH₂、CoA、乙酰 CoA。**必须明确标注二者的从属关系**：NADP⁺ = 辅酶Ⅱ；FAD = 黄素腺嘌呤二核苷酸（辅基），不得写成"辅酶Ⅱ"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择 NAD⁺ 并投入呼吸链 | 显示 NAD⁺ → NADH 的加氢过程 | 理解递氢 |
| 选择 NADP⁺ 并投入光反应 | 显示 NADP⁺ → NADPH 并还原 C₃ | 区分两类还原力 |
| 查看 FAD | 提示"含维生素 B₂ 的辅基，非辅酶Ⅱ" | 纠正命名错误 |

| 完成名称配对题 | NADP⁺↔辅酶Ⅱ、FAD↔黄素腺嘌呤二核苷酸 | 巩固对应关系 |

## 9. 参数与模型

- NADH 经呼吸链约产生 2.5 ATP，FADH₂ 约 1.5 ATP（教材简化常写 3 与 2，需在文案注明口径差异）
- NADPH 不进入呼吸链产能，专用于还原性合成

## 12. 现有实现问题

> **存在明确的科学性错误，P0 必修。**

- 现有配置把 `FAD` 标注为"**辅酶Ⅱ 类黄素**"——辅酶Ⅱ 是 NADP⁺，FAD 是黄素腺嘌呤二核苷酸（通常作辅基）。这是本书面最容易误导学生的错误，必须立即修改
- 卡片中"每分子经呼吸链泵出质子较少（约 1.5 ATP）"表述混淆了"泵出质子数"与"生成 ATP 数"，建议改为"FADH₂ 进入呼吸链生成的 ATP 少于 NADH"
- 未包含 NADP⁺/NADPH，导致光合作用还原力缺失，无法与光反应衔接
