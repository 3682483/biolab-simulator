## 2. 学科定位

人教版必修一第 6 章第 3 节。课标要求：说明细胞凋亡与坏死的区别，认同细胞凋亡对个体发育的意义。前置：细胞衰老；后续：免疫调节（靶细胞清除）、癌变、发育生物学。

## 3. 教学目标

1. 能说明细胞凋亡是**由基因决定的程序性死亡**，属主动过程，对个体有利。
2. 能说明细胞坏死是**外界不利因素引起的被动死亡**，常伴随炎症反应。
3. 能举例说明凋亡在发育与免疫中的作用（蝌蚪尾部消失、手指蹼消失、被感染细胞被清除）。
4. 能按"谁决定、主动/被动、有利/有害"三问判别两者。

## 4. 知识点解析

必须准确表述：

| 比较项 | 细胞凋亡 | 细胞坏死 |
| --- | --- | --- |
| 决定因素 | 基因决定的程序性死亡 | 外界因素（高温、强酸强碱、缺氧、病原体） |
| 主动性 | 主动、有序 | 被动、无序 |
| 对个体 | 有利（维持稳态、完成发育） | 有害（引发炎症） |
| 形态变化 | 细胞萎缩、形成凋亡小体、被吞噬 | 细胞肿胀、破裂、内容物外溢 |
| 是否发炎 | 不引起炎症 | 引起炎症 |

- 凋亡实例：蝌蚪尾部细胞自动消失、人胚胎期手指间蹼消失、被病原体感染的细胞被效应 T 细胞清除、衰老细胞被清除。
- 坏死实例：烫伤、强碱灼伤、缺血导致的组织溃烂。

常见错误概念：

1. 认为细胞死亡都是坏事（凋亡是正常生理过程，对个体有利）。
2. 认为凋亡是"被动死亡"（凋亡是基因控制的主动过程）。
3. 认为凋亡只发生在胚胎期（贯穿个体一生）。
4. 把"被效应 T 细胞清除的靶细胞"当作坏死（属凋亡）。

## 5. 界面设计

主画布：同一细胞在两种命运下的形态对比（凋亡：皱缩→凋亡小体→被吞噬；坏死：肿胀→破裂→炎症）。控制区：诱因选择（基因调控 / 高温 / 强碱 / 病原体感染）、两桶分类、时间轴播放。数据区：细胞体积、膜完整性、是否释放内容物、是否引发炎症。讲解区：判别三问。

## 6. 互动素材

凋亡形态变化动画（形成凋亡小体并被巨噬细胞吞噬）、坏死破裂动画（内容物外溢、炎症细胞聚集）、实例卡片。

## 7. 标注要求

等级 **A2**。标注项：凋亡小体、巨噬细胞、细胞膜完整性、内容物外溢、炎症细胞。必须标注"凋亡不引起炎症"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择"基因调控"诱因 | 细胞皱缩、形成凋亡小体、被吞噬，无炎症 | 建立凋亡特征 |
| 选择"强碱"诱因 | 细胞肿胀破裂、内容物外溢、炎症细胞聚集 | 建立坏死特征 |
| 拖拽实例卡片入桶 | 正确入桶并播放对应动画 | 巩固判别 |
| 完成三问判定 | 逐项回答决定因素/主动性/利害 | 形成可迁移方法 |

## 9. 参数与模型

- 形态判定：凋亡细胞体积缩小、膜完整（形成小体）；坏死细胞体积增大、膜破裂
- 炎症标记：坏死触发炎症指示，凋亡不触发

## 10. 三维与可视化规范

等级 **L2**：凋亡小体形成与内容物外溢有空间过程，可用 2.5D 剖面动画；不需真三维。
