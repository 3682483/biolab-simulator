## 2. 学科定位

人教版必修一第 6 章第 3 节。课标要求：描述细胞衰老的特征，说明细胞衰老与个体衰老的关系。前置：细胞结构与代谢；后续：细胞凋亡、癌变、个体衰老。

## 3. 教学目标

1. 能列举衰老细胞的主要特征（水分减少、酶活性降低、色素积累、核体积增大核膜内折、膜通透性改变）。
2. 能说明细胞衰老不等于个体衰老：多细胞生物体内细胞衰老与新生同时存在。
3. 能说明个体衰老是组成个体的细胞普遍衰老的过程。
4. 能说明细胞衰老由基因决定（端粒学说、自由基学说）。

## 4. 知识点解析

必须准确表述：

| 结构/功能 | 衰老表现 |
| --- | --- |
| 水分 | 细胞内水分减少，细胞萎缩、体积变小 |
| 代谢 | 多种酶活性降低，呼吸速率减慢，代谢速率下降 |
| 色素 | 脂褐素等色素逐渐积累 |
| 细胞核 | 核体积增大、核膜内折、染色质收缩染色加深 |
| 细胞膜 | 通透性改变，物质运输功能降低 |

- 细胞衰老 ≠ 个体衰老：幼年个体也有衰老细胞（如皮肤角质层），老年个体也有新生细胞（如造血干细胞）。
- 个体衰老是细胞普遍衰老的过程。
- 衰老机制学说：端粒学说（端粒缩短）、自由基学说（自由基攻击生物膜与 DNA）。

常见错误概念：

1. 认为细胞衰老必然导致个体衰老（两者不等同）。
2. 认为衰老细胞的代谢全部停止（代谢减弱但仍在进行）。
3. 认为衰老细胞核体积缩小（实为增大、核膜内折）。
4. 认为幼年个体没有衰老细胞。

## 5. 界面设计

主画布：细胞剖面对比（年轻细胞 / 衰老细胞并排），可切换观察项。控制区：特征卡库、两桶分类、观察项切换（水分/酶/色素/核/膜）。数据区：各指标对比条（水分、酶活性、色素量、核体积）。讲解区：细胞衰老与个体衰老的关系图。

## 6. 互动素材

年轻/衰老细胞对比模型、脂褐素颗粒累积动画、核膜内折示意、端粒缩短示意（染色体末端）。

## 7. 标注要求

等级 **A2**。标注项：细胞核、核膜、脂褐素、细胞膜、端粒。必须标注"核体积增大、核膜内折"这一反直觉特征。

## 9. 参数与模型

- 指标方向：水分↓、酶活性↓、脂褐素↑、核体积↑、膜通透性改变（非单向高低，需描述"改变"）
- 不做定量数值，只做方向对比（微实验定位）
