## 2. 学科定位

人教版必修二第 3 章（DNA 复制）综合题型。课标要求：理解 DNA 半保留复制，能推算带标记染色体/配子的比例。前置：DNA 半保留复制、有丝分裂与减数分裂；后续：分子遗传学综合题。

## 3. 教学目标

1. 能用半保留复制解释"一深一浅"的两条子链。
2. 能推算有丝分裂 n 次后带标记 DNA 分子数恒为 **2**，占比 1/2ⁿ⁻¹。
3. 能推算减数分裂产生的配子中带标记者占 **1/2**。
4. 能说明"带标记染色体比例"与"带标记 DNA 链比例"的区别。

## 4. 知识点解析

必须准确表述：

- 亲代 DNA 双链均含标记（如 ³H 全标），转入无标记培养液进行半保留复制。
- 第 1 次复制：2 条子 DNA，各含 1 条母链（有标记）+ 1 条新链（无标记）→ 全部带标记。
- 有丝分裂 n 次后：共 2ⁿ 个 DNA 分子，含标记的始终只有 **2 个**（两条母链各进入一个分子），占比 = 2/2ⁿ = 1/2ⁿ⁻¹。
- 减数分裂：DNA 复制 1 次、连续分裂 2 次，形成的 4 个子细胞中 2 个带标记 → 配子带标记比例 **1/2**。
- 注意区分：带标记的"染色体数目比例"与"DNA 分子比例"在有丝分裂中期可能因姐妹染色单体而表述不同，需按"中期每条染色体含 2 条单体"换算。

常见错误概念：

1. 认为复制次数越多带标记分子越多（恒为 2 个）。
2. 把"染色体带标记比例"与"DNA 带标记比例"混为一谈（后期着丝粒分裂后二者数值不同）。
3. 认为减数分裂后带标记配子比例为 1/4（实为 1/2）。
4. 忘记"标记的是母链"，误把新链当作标记链。

## 5. 界面设计

主画布：DNA 双链示意（母链深色、新链浅色）+ 分裂次数推进。控制区：复制次数 n（1–4）、分裂类型（有丝/减数）、观察层级（DNA/染色体/配子）。数据区：带标记 DNA 数、总 DNA 数、比例、染色体带标记情况。讲解区：链谱图绘制提示。

## 6. 互动素材

DNA 双链两种颜色的链谱图、复制叉动画、染色体着丝粒分裂示意、配子产物列表（带标记着色）。

## 7. 标注要求

等级 **A2**。标注项：母链（标记）、新链（无标记）、姐妹染色单体、着丝粒、DNA 分子。必须标注"含标记 DNA 恒为 2 个"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 第 1 次复制 | 两条子 DNA 均"一深一浅" | 理解半保留 |
| 推进至第 2、3 次 | 带标记分子仍为 2，比例随 1/2ⁿ⁻¹ 下降 | 掌握恒为 2 |
| 切换减数分裂 | 4 个配子中 2 个带标记 | 掌握 1/2 |
| 切换观察层级 | DNA 比例与染色体比例分别显示 | 区分两种口径 |
| 绘制链谱并作答 | 系统比对链谱与比例 | 训练方法而非背答案 |

## 9. 参数与模型

- 有丝分裂 n 次：带标记 DNA = 2，比例 = 2/2ⁿ = 1/2ⁿ⁻¹（n ≥ 1）
- 减数分裂：带标记配子 = 2/4 = 1/2
- 若问"中期带标记染色体比例"：每条染色体含 2 条单体，答案与 DNA 比例相同；若问"后期"，着丝粒分裂后仍为同一比例但基数变化，需明确分母

## 10. 三维与可视化规范

等级 **L1**：链谱与计数用 2D 表达最清晰。可用简单三维双螺旋增强直观性，但不作为理解依赖。
