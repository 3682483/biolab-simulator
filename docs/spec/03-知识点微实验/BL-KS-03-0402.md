## 2. 学科定位

人教版必修一、必修二综合题型。课标要求：能根据图像或时期判断染色体、DNA、染色单体的数量关系。前置：有丝分裂、减数分裂；后续：分裂异常判断、复制标记判断。

## 3. 教学目标

1. 能同时读出任一时期的染色体数、DNA 数、染色单体数三项数值。
2. 能说明染色单体数的两种取值：0 或 2×染色体数（正常细胞）。
3. 能区分"DNA 加倍"（S 期）与"染色体加倍"（着丝粒分裂后）。
4. 能判断同源染色体是否存在、同源染色体对数。

## 4. 知识点解析

必须准确表述：

- 三项计数的关系：
  - 有染色单体时：染色单体数 = DNA 数 = 2 × 染色体数
  - 无染色单体时（着丝粒已分裂）：染色单体 = 0，DNA 数 = 染色体数
- DNA 加倍发生在**间期 S 期**（DNA 复制），此时染色体数不变。
- 染色体数加倍发生在**后期着丝粒分裂**后，此时染色单体数变为 0。
- 同源染色体：有丝分裂全过程存在；减Ⅰ存在（分离前）；减Ⅱ**不存在**。
- 2n = 4 的典型取值：
  - 有丝分裂中期：染色体 4、DNA 8、单体 8
  - 有丝分裂后期：染色体 8、DNA 8、单体 0
  - 减Ⅰ后期：染色体 4、DNA 8、单体 8（同源分离中）
  - 减Ⅱ后期：染色体 4、DNA 4、单体 0（无同源）

常见错误概念：

1. 认为"DNA 加倍"就等于"染色体加倍"。
2. 认为有染色单体时 DNA 数 = 染色体数。
3. 认为减Ⅱ后期存在同源染色体。
4. 口诀记忆但不理解：遇到后期就认为"染色体数一定为 2n"（有丝分裂后期是 4n）。

## 5. 界面设计

主画布：细胞图像区（可按时期切换，显示染色体形态）+ 三项计数柱状对比。控制区：时期选择（有丝间期/前期/中期/后期/末期、减Ⅰ前中后末、减Ⅱ前中后末）、2n 设定。数据区：染色体、DNA、染色单体、同源染色体对数四项读数。讲解区：判定步骤（先看有无单体 → 再看是否分裂后期）。

## 6. 互动素材

染色体形态图（含/不含姐妹染色单体两种）、计数柱状图、同源染色体配对示意、判定流程卡。

## 7. 标注要求

等级 **A2**。标注项：染色体、姐妹染色单体、着丝粒、同源染色体、DNA 数、染色单体数。必须标注"染色单体数 = 0 或 2×染色体数"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 选择某时期 | 图像与四项计数同步更新 | 建立时期—数量对应 |
| 点击"数一数" | 图像上逐条高亮并累计 | 训练数图能力 |
| 切换到有丝后期 | 染色体 4→8、单体 8→0 | 区分两种加倍 |
| 切换到减Ⅱ后期 | 提示"无同源染色体" | 避免同源误判 |
| 输入自定义图像 | 系统校验三项计数是否自洽 | 训练自检 |

## 9. 参数与模型

- 以 2n = 4 为默认，可切换 2n = 6、8
- 自洽校验规则：单体 ∈ {0, 2×染色体}；单体 = 0 → DNA = 染色体；单体 > 0 → DNA = 单体
- 非法组合（如单体 = 3 而染色体 = 4）必须报"该组合不存在于正常细胞"

## 10. 三维与可视化规范

等级 **L1**：以图像与数值表为主，二维即可完整表达数量关系；三维无增益。

## 11. 验收标准

- [ ] 覆盖有丝分裂与减数分裂全部主要时期（≥ 10 个）
- [ ] 四项计数在各时期均正确
- [ ] 有丝后期染色体数为 4n，减Ⅱ后期无同源染色体
- [ ] 自洽校验能识别非法组合
- [ ] 提供"数图"交互，不只给结论
