## 2. 学科定位

人教版必修二第 2 章第 1 节。课标要求：比较精子与卵细胞形成的异同。前置：减数分裂过程（BL-SIM-03-03）；后续：受精作用、伴性遗传、性别决定。

## 3. 教学目标

1. 能说明卵细胞形成过程中两次细胞分裂均为**不均等分裂**。
2. 能说明 1 个卵原细胞最终形成 1 个卵细胞 + 3 个极体（极体退化消失）。
3. 能说明卵细胞体积大、细胞质富含营养，为早期胚胎发育提供物质基础。
4. 能对比精子形成（均等分裂，1→4，需变形）与卵细胞形成的差异。

## 4. 知识点解析

必须准确表述：

| 比较项 | 精子形成 | 卵细胞形成 |
| --- | --- | --- |
| 细胞质分裂 | 均等 | **不均等**（两次均不均等） |
| 产物数量 | 1 个精原细胞 → 4 个精细胞 | 1 个卵原细胞 → 1 个卵细胞 + 3 个极体 |
| 是否变形 | 精细胞变形为精子 | 不需变形 |
| 细胞质分配 | 均分 | 几乎全部集中于卵细胞 |
| 场所 | 睾丸曲细精管 | 卵巢 |

- 减Ⅰ：初级卵母细胞 → 次级卵母细胞（大）+ 第一极体（小）。
- 减Ⅱ：次级卵母细胞 → 卵细胞（大）+ 第二极体（小）；第一极体也可分裂为两个极体。
- 极体最终退化消失，不为后代提供遗传物质（但含核 DNA）。

常见错误概念：

1. 认为卵细胞形成也是均等分裂（两次均不均等）。
2. 认为 1 个卵原细胞产生 4 个卵细胞（只产生 1 个卵细胞 + 3 个极体）。
3. 认为极体与卵细胞同等重要（极体退化，主要作用是排出多余染色体）。
4. 认为卵细胞体积大的原因是染色体多（染色体数同为 n，体积大是细胞质储备）。

## 5. 界面设计

主画布：卵巢内卵原细胞发育的 4 阶段剖视图，突出两次不均等分裂的大小差异。控制区：阶段推进、与精子形成并排对比、极体显隐。数据区：细胞体积比、染色体数、产物统计。讲解区：精子与卵细胞形成对照表。

## 6. 互动素材

不均等分裂动画（大细胞与小极体）、极体退化示意、卵细胞营养储备（卵黄颗粒）、与精子形成的并排对照视图。

## 7. 标注要求

等级 **A2**。标注项：卵原细胞、初级卵母细胞、次级卵母细胞、卵细胞、第一极体、第二极体、细胞质。必须标注"两次均不均等分裂"。

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 推进减Ⅰ | 不均等分裂为次级卵母细胞 + 第一极体 | 认识第一次不均等 |
| 推进减Ⅱ | 再次不均等，产生卵细胞 + 第二极体 | 认识第二次不均等 |
| 统计产物 | 显示 1 卵 + 3 极体，极体标灰退化 | 纠正"4 个卵细胞" |
| 切换对比模式 | 并排显示精子形成（均等、4 个、需变形） | 掌握差异 |
| 查看细胞质分配 | 显示卵细胞获得绝大部分细胞质与营养 | 理解"以质取胜" |

## 9. 参数与模型

- 示例 2n = 4：卵细胞 n = 2，极体 n = 2
- 体积比示意：卵细胞 : 极体 ≈ 10 : 1（示意值，需标注非精确）
- 产物统计固定为 1 + 3

## 10. 三维与可视化规范

## 12. 现有实现问题
