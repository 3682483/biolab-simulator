# BioLab 仿真实验 Spec 编码规范与文档模板

> 版本 v1.0 ｜ 适用对象：469 条实验项目（41 自研仿真 + 347 重制实验 + 81 知识点微实验）
> 用途：作为重新制作的技术交付物，任何一份 spec 交给生物教研与前端开发，都应能直接开工

---

## 一、编码体系

### 1.1 编码格式

| 类型 | 编码 | 示例 | 数量 |
| --- | --- | --- | --- |
| 自研仿真（独立组件） | `BL-SIM-{模块号}-{序号}` | `BL-SIM-02-01` | 41 |
| 重制实验（框架配置） | `BL-RMD-{册}-{序号}` | `BL-RMD-BX1-012` | 347 |
| 知识点微实验 | `BL-KS-{模块号}-{分类号}{知识点号}` | `BL-KS-01-0103` | 81 |

规则：

- `模块号` 取知识地图模块，两位数字：`01`–`10`（01 细胞的结构基础 … 10 实验与探究）
- `册` 取教材册别：`BX1`（必修一）、`BX2`（必修二）、`XX1`–`XX3`（选择性必修一至三）、`CZ1`–`CZ4`（初中四册）
- `序号` **沿用现有数据源 id 中的序号**，保证可回溯：
  - SIM：两位，按模块内注册顺序（`01`–`06`…），一旦分配不再变动
  - RMD：三位，取 legacy id 尾号（`bx1-012` → `BL-RMD-BX1-012`）
  - KS：四位，前两位为分类号、后两位为知识点号（`module-10-section-06-topic-09` → `BL-KS-10-0609`），避免同模块不同分类的 topic 序号冲突

### 1.2 文件与目录

```text
docs/spec/
├─ 00-编码规范与模板.md      # 本文件
├─ index.md                  # 全量 469 条索引（编码 / 标题 / 模块 / 现实现 / 三维等级 / 标注等级）
├─ 01-自研仿真/              # BL-SIM-*
├─ 02-重制实验/              # BL-RMD-*
└─ 03-知识点微实验/          # BL-KS-*
```

文件名即编码：`01-自研仿真/BL-SIM-01-01.md`。

### 1.3 三层可追溯关系

```text
知识点（knowledge-map：10 模块 / 44 分类 / 200 知识点）
   ↑ 被覆盖
实验（SIM / RMD / KS）—— 编码唯一，一个实验可覆盖多个知识点，一个知识点可被多个实验覆盖
   ↑ 承载
交互素材（3D 模型 / 2D 图元 / 数据曲线 / 标注锚点 / 参数控件）
```

任何 spec 必须写明：本实验覆盖哪些知识点（用知识点 ID），以及本实验与同知识点其他实验的**分工**（谁讲原理，谁做验证，谁做定量）。

## 二、三维等级（3D Level）

"能用三维就用三维"不等于全部三维。按教学收益判定，写入每份 spec：

| 等级 | 名称 | 适用 | 技术要求 |
| --- | --- | --- | --- |
| **L3** | 真三维 | 空间结构必须靠转动/剖面才能理解的对象：细胞器、生物膜、蛋白质四级结构、DNA/RNA、染色体、病毒、器官与系统、显微镜等装置 | Three.js / WebGL，可自由旋转与缩放，支持剖面、半透明、结构高亮；三角面预算 ≤ 30 万，桌面 60fps、移动端 ≥ 30fps |
| **L2** | 2.5D | 有空间感但以过程为主：分泌蛋白运输、光合电子传递链、跨膜运输、减数分裂纺锤体、神经冲动传导 | 轴测视角或分层视差，允许伪三维旋转（±25°），不要求真网格 |
| **L1** | 2D 矢量 + 动效 | 以数量关系、曲线、流程、表格为核心的实验：酶促反应曲线、种群增长、遗传比例、电泳条带读数、实验装置流程 | SVG / Canvas，矢量清晰、可缩放不失真，动效仅服务于因果表达 |

判定三问（任一为是即升一级）：

1. 学生是否需要"转个角度才看懂"？→ L3
2. 空间层叠关系是否是易错点？→ L2 起
3. 只靠曲线或图示能否说清因果？→ L1 足够

### 2.1 三维素材硬性要求

- **比例可信**：细胞器相对大小、膜厚比、分子尺度差异不得为美观而随意放大，必要时标注"比例失真"提示
- **结构命名**：一律采用人教版高中生物术语；同一结构全校统一（如"类囊体"不写"基粒片层"，"核糖体"不写"核蛋白体"）
- **颜色语义**：不得用颜色区分物种/材料以外的无关维度；同一结构在所有实验中使用同一色系（建立全局色板）
- **动效克制**：结构旋转默认关闭，用户主动操作；自动演示时相机运动一次只允许一个自由度

## 三、标注等级（Annotation Level）

| 等级 | 名称 | 组成 | 适用 |
| --- | --- | --- | --- |
| **A3** | 空间锚点标注 | 三维锚点 + 引线 + 结构卡（中文名 / 英文名 / 一句话功能）+ 分层显隐 + 点击聚焦 | L3、L2 且结构数 ≥ 6 |
| **A2** | 编号标注 | 图内编号 + 右侧图例列表（编号 / 名称 / 功能），支持点击联动高亮 | L2、L1 且结构数 3–6 |
| **A1** | 文字说明 | 图注或面板文字，不做空间锚定 | 结构数 ≤ 2，或纯数值/流程类 |

标注硬性要求：

- 命名必须与教材一致，英文名可省略但中文名不可臆造
- 每条标注必须给"功能"，不允许只给名称
- 标注遮挡控制：标注密度 ≤ 视口面积 15%，重叠时自动错位或收纳为序号
- A3 锚点必须绑定模型节点（node/mesh），模型旋转时随动，不许贴屏幕坐标

## 四、Spec 文档模板

每份 spec 固定 13 节，顺序不可调整。无内容的小节写"不适用"，不得省略。

```markdown
# {编码} {标题}

## 1. 基本信息
| 项 | 内容 |
| --- | --- |
| 编码 | BL-XXX-XX-XX |
| 类型 | 自研仿真 / 重制实验 / 知识点微实验 |
| 所属册·模块 | 必修一 · 模块一 细胞的结构基础 |
| 覆盖知识点 | module-01-section-01-topic-01（1. 细胞中的元素） |
| 建议时长 | 6 分钟 |
| 难度 | 基础 / 中等 / 挑战 |
| 现有实现 | 组件 CellElements.tsx / frame=builder / 无 |

## 2. 学科定位
教材章节、课标要求（内容要求/学业要求）、前置知识、后续知识。

## 3. 教学目标
3–4 条可观测目标，动词用"能说明 / 能判断 / 能计算 / 能区分"。

## 4. 知识点解析
核心概念定义、必须准确的科学表述（列出易被写错的句子）、常见错误概念（ misconceptions，至少 2 条）。

## 5. 界面设计
布局分区（画布区 / 控制区 / 数据区 / 讲解区）与各区域职责、控件清单、状态反馈。

## 6. 互动素材
模型与图元清单（3D 资产、SVG 部件、数据曲线、动画轨），每项注明用途与复用来源。

## 7. 标注要求
等级（A1–A3）、标注清单表（名称 / 英文 / 功能 / 锚点位置）。

## 8. 交互流程
分阶段脚本：每阶段列出「用户动作 → 系统响应 → 教学意图」三列。

## 9. 参数与模型
定量关系式、初值、取值范围、边界条件、容差与判定阈值。

## 10. 三维与可视化规范
等级（L1–L3）、相机与视角、材质与配色、性能预算、降级方案。

## 11. 验收标准
可测条目（勾选式），每条对应一个可观察结果。

## 12. 现有实现问题
针对当前版本的缺陷清单：科学性错误、交互缺陷、缺失能力。

## 13. 制作优先级
P0（科学性错误必须修）/ P1（交互体验）/ P2（增强），并给出预估人日。
```

## 五、专业质量红线

任何 spec 与后续实现，违反任一条即打回：

1. **科学性**：概念表述、结构命名、定量关系必须与现行人教版教材一致；有争议的表述须注明依据
2. **可测性**：每个教学目标必须能在界面上被观察到，不接受"让学生理解 X"这类不可验证目标
3. **因果可见**：参数改变必须引起可解释的视觉变化，不接受"动画演示但参数无效"
4. **易错点覆盖**：每个实验至少显式处理 2 个学生常见错误概念
5. **无伪交互**：不得用"点击下一步播放动画"冒充交互，用户操作必须改变模型状态
6. **标注完整性**：所有结构在首次出现时必须有标注，且标注随模型变换正确随动
7. **性能**：首屏 ≤ 1.5s（本地），交互响应 ≤ 100ms，3D 场景切换 ≤ 400ms
8. **可离线**：不依赖任何外部 CDN 与网络请求（Draco 解码器已本地化）
