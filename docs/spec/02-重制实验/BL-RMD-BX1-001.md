## 2. 学科定位

人教版必修一第 2 章第 5 节、必修二第 3 章第 2 节。本实验承担"结构搭建"环节：学生在搭建过程中理解基本骨架、碱基互补配对与双螺旋形态。前置：核苷酸组成；后续：DNA 复制（BL-RMD-BX1-0xx）、转录。

## 3. 教学目标

1. 能按"磷酸—脱氧核糖—碱基"顺序正确组装一个脱氧核苷酸。
2. 能将两条反向平行的核苷酸链通过碱基互补配对连接成双螺旋。
3. 能说明 A—T 2 个氢键、G—C 3 个氢键，并解释 GC 含量与稳定性的关系。
4. 能识别并排除错误部件（肽键、尿嘧啶等）。

## 4. 知识点解析

必须准确表述：

- 一分子脱氧核苷酸 = 一分子磷酸 + 一分子脱氧核糖 + 一分子含氮碱基（A/T/G/C）。
- DNA 由两条反向平行的脱氧核苷酸链构成，外侧为磷酸与脱氧核糖交替连接的基本骨架，内侧碱基对以氢键相连。
- A 与 T 配对形成 2 个氢键，G 与 C 配对形成 3 个氢键；GC 含量越高，DNA 热稳定性越高。
- 1953 年沃森与克里克提出 DNA 双螺旋结构模型（需注明依据：威尔金斯与富兰克林的 X 射线衍射、查哥夫法则）。

常见错误概念：

1. 把尿嘧啶 U 当作 DNA 的组成碱基（U 只存在于 RNA）。
2. 认为两条链方向相同，或认为碱基对位于双螺旋外侧。
3. 认为任意两个碱基都能配对（嘌呤与嘌呤、嘧啶与嘧啶不配对）。
4. 认为氢键数对稳定性无影响（GC 比例高的片段更难解链）。

## 5. 界面设计

| 区域 | 内容 |

| 控制区 | 搭建/观察模式切换、碱基类型选择、撤销与重置、旋转与缩放 |
| 数据区 | 已配对碱基统计、氢键总数、GC 含量与稳定性指示 |

## 6. 互动素材

- 脱氧核苷酸三维部件（磷酸球、脱氧核糖五元环、四种碱基色块）
- 双螺旋生长动画（骨架沿螺旋轴延伸，碱基对自动朝向内侧）
- 氢键可视化（A—T 双虚线、G—C 三虚线）
- 干扰部件：肽键、尿嘧啶、核糖（用于辨析）

## 7. 标注要求

等级 **A3**。标注项：磷酸、脱氧核糖、含氮碱基、碱基对、氢键、基本骨架、反向平行。要求：

- 标注必须绑定模型节点，旋转与缩放时引线随动
- 氢键标注需显示数量（2 / 3）
- 骨架标注需指向"磷酸—脱氧核糖交替"的具体区段，而非泛指标注
- 双螺旋两端各标一次"5′端 / 3′端"，用于呈现反向平行

## 8. 交互流程

| 用户动作 | 系统响应 | 教学意图 |
| --- | --- | --- |
| 从部件库拖入磷酸与脱氧核糖 | 自动吸附成长链骨架，错误顺序则回弹并提示 | 掌握核苷酸组成 |
| 选择碱基并放置到待配对位 | 按互补原则判定：A 位只能放 T，G 位只能放 C | 内化配对规则 |
| 放置成功 | 生成对应数量氢键并计入统计 | 建立"配对—氢键数"对应 |
| 误放干扰部件（肽键/U/核糖） | 明确提示该部件属于蛋白质或 RNA | 辨析三类大分子 |
| 完成 10 对以上 | 双螺旋自动闭合成螺旋形态，显示 5′/3′ 端 | 理解反向平行与螺旋 |
| 调节 GC 含量 | 稳定性指示条与解链难度联动 | 理解稳定性差异 |

## 9. 参数与模型

- 默认搭建长度：12 个碱基对；可扩展至 24 bp
- 氢键数：A—T = 2，G—C = 3；总氢键数 = 2×(AT 对数) + 3×(GC 对数)
- 稳定性指标：以 GC 百分比映射至 0–100 的指示条，标注"定性示意"
- 螺旋参数：每圈 10 个碱基对，螺距 3.4 nm，直径 2 nm（示意可等比）

## 10. 三维与可视化规范

等级 **L3**（现有 `builder` 框架不满足，需升级）。相机：默认斜 30° 观察，可环绕；搭建时相机锁定，观察模式解除锁定并允许缩放至单碱基对。材质：骨架磨砂塑料感，碱基四色（A 绿、T 橙、G 蓝、C 黄，全站统一），氢键用半透明虚线管。面数 ≤ 15 万；拖拽时使用简化代理体，落位后替换为完整模型。

## 11. 验收标准

- [ ] 核苷酸组装顺序正确，错误顺序有明确反馈
- [ ] 碱基配对严格遵循 A—T、G—C，不允许非互补配对落位
- [ ] 氢键数量统计准确（2/3 区分）
- [ ] 双螺旋显示反向平行（两端 5′/3′ 标注正确）
- [ ] 干扰部件（肽键、U、核糖）被拒绝并给出归属说明
- [ ] 标注随旋转缩放随动，无脱锚与遮挡堆叠

## 12. 现有实现问题

> 基于现有 `builder` 配置可确认的问题。

- 纯卡片拖拽（4 槽位 + 6 部件），只能验证"哪个部件放哪个槽"，无法体现空间结构，与"DNA 结构"教学目标错位
- 无氢键数量、GC 含量、稳定性相关内容
- 无双螺旋与反向平行可视化，"结构搭建"实际退化为连线题
- 干扰项（肽键、U）设计合理，但反馈仅一句 fact，未说明其所属分子类别
